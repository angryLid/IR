## When to Use

当用户要求研究 A 股原料加工业上市公司时激活。判断依据：

- 公司属于食品添加剂、生物制造、精细化工、农产品加工、饲料添加剂等原料加工板块
- 核心特征：商品原材料为主要投入成本（占营业成本 30%+），毛利率随原材料价格周期波动
- 重资产特征：固定资产占总资产 30%+，资本开支持续高于折旧
- 用户明确提及"原料加工""食品添加剂""生物制造""发酵"等关键词

典型适用公司：安琪酵母(600298)、梅花生物(600873)、凯赛生物(688065)、华恒生物(688639)、新和成(002001)、中粮科技(000930)、星湖科技(600866)等。

本 skill 补充 AGENTS.md 通用研究规范中**原料加工业特有的处理逻辑**。通用规则（数据来源优先级、报告目录结构、免责声明等）仍遵循 AGENTS.md。

### 原料加工公司需额外关注的字段

从三表中提取时，除通用科目外，重点关注以下原料加工业特有科目：

**利润表：**
- 营业成本（用于计算毛利率，反映原材料成本传导能力）
- 财务费用（有息负债利息，原料加工企业通常负债率较高）
- 研发费用（技术壁垒的核心指标）
- 资产减值损失（存货跌价、固定资产减值）

**资产负债表：**
- 固定资产原值/累计折旧/净值（重资产核心科目）
- 在建工程（未来产能储备，预示增长潜力）
- 存货明细（原材料 vs 在产品 vs 产成品，反映原材料备货策略）
- 有息负债（短期借款 + 长期借款 + 应付债券，用于计算 EV）
- 商誉及无形资产（技术/菌种/专利价值）

**现金流量表：**
- 购建固定资产、无形资产支付的现金（资本开支，区分维持性 vs 扩张性）
- 折旧摊销（用于 EBITDA 计算，通常在附注或间接法补充资料中）
- 分配股利支付的现金（分红能力与意愿）
- 取得借款收到的现金 / 偿还债务支付的现金（融资节奏）

## Step 2: 原料加工业专用财务指标

通用模板的毛利率/净利率/ROE 仍然适用，但原料加工业需要增加以下**行业专用指标维度**：

### 2a. 核心财务指标表

| 指标 | 含义 | 健康趋势 |
|------|------|---------|
| 营业收入 | 总营收 | 稳定增长 |
| 营收增速 | YoY 增长率 | 关注周期性波动 |
| 净利润 | 归母净利润 | 稳定增长（关注周期性） |
| 净利润增速 | YoY 增长率 | 波动大=周期性强 |
| 毛利率 | (营收 - 营业成本) / 营收 | **核心指标**，随原材料周期波动 |
| 净利率 | 归母净利润 / 营收 | 关注趋势 |
| ROE | 归母净利润 / 平均净资产 | >12% 为优秀 |
| ROIC | NOPAT / (净资产 + 有息负债 - 现金) | >WACC 为创造价值 |
| 固定资产 / 总资产 | 重资产程度 | 行业内对比 |
| 折旧 / 营业收入 | 折旧负担 | 关注趋势，折旧高峰期压低利润 |
| 资本开支 / 营业收入 | 扩张强度 | 高=扩张期，低=成熟期 |

| 资产负债率 | 总负债 / 总资产 | 关注有息负债占比 |

## Step 3: 估值方法

原料加工业公司估值**至少使用以下三种方法中的两种**交叉验证。三种全部使用更佳。

### 3a. Normalized Earnings + EV/EBITDA —— 原料加工业首选

**适用理由：**
- 原材料价格周期导致单年 PE 失真（盈利高点 → 低 PE → 看似便宜；盈利低点 → 高 PE → 看似昂贵）
- 重资产 + 高折旧使 EV/EBITDA 比 PE 更能反映经营盈利能力
- 消除折旧政策差异和资本结构差异，更适合跨国/跨公司可比

**计算步骤：**

1. **识别原材料价格周期**（通常 3-5 年一个完整周期）
2. **计算周期内毛利率中值/均值** → Normalized 毛利率
3. **用 Normalized 毛利率重算 EBITDA 和净利润：**
   - Normalized EBITDA = 营收 × Normalized EBITDA Margin
   - Normalized 净利润 = 营收 × Normalized 净利率
4. **计算 EV：**
   - EV = 市值 + 有息负债（短期借款 + 长期借款 + 应付债券） - 现金及等价物
5. **可比公司 EV/EBITDA 中位数 × Normalized EBITDA = 隐含 EV**
6. **隐含 EV - 有息负债 + 现金 = 股权价值 → 每股价值**

**Normalized Earnings 计算表模板：**

```
| 指标 | 周期高点 | 周期低点 | 周期均值 | 当前值 | 偏离度 |
|------|---------|---------|---------|--------|--------|
| 毛利率 | | | | | |
| EBITDA Margin | | | | | |
| 净利率 | | | | | |
| EPS（元） | | | | | |
| EBITDA（亿元） | | | | | |
```

**校正方法说明：**
- 取最近一个完整原材料价格周期的均值/中位数
- 或用中值化原材料价格重新计算毛利率
- 注明采用的校正方法及理由

**敏感性分析网格：**

| | EV/EBITDA -2x | EV/EBITDA 基准 | EV/EBITDA +2x |
|------|-------------|-------------|-------------|
| Normalized EBITDA +10% | | | |
| Normalized EBITDA 基准 | | | |
| Normalized EBITDA -10% | | | |

### 3b. DCF 估值 —— 含产能扩张周期建模

**适用理由：** 可反映产能投放节奏和原材料周期对 FCF 的影响，适合长期价值评估。

**模型选择：** 两阶段 DCF（显式预测期 + 永续期）

```
企业价值 = Σ [FCF_t / (1+WACC)^t]  (t=1..N) + [FCF_{N+1} / (WACC - g_terminal)] / (1+WACC)^N
每股价值 = (企业价值 - 净负债) / 总股本
```

**原料加工业 DCF 建模要点：**

1. **收入预测分解为产能 × 利用率 × 单价：**
   - 收入 = 设计产能 × 产能利用率 × 单位产品价格
   - 产能增速：参考在建工程和公告中的扩产计划
   - 产能利用率：投产后逐步达产，通常 80%-95%
   - 单价增速：取决于产品差异化程度和议价能力（0%-5%）

2. **毛利率预测应分原材料周期阶段：**
   - 扩张期（原材料低价）：毛利率高于均值
   - 收缩期（原材料高价）：毛利率低于均值
   - 终端期：使用 Normalized 毛利率

3. **capex 分拆：**
   - 维持性 capex ≈ 折旧（维持现有产能）
   - 扩张性 capex = 总 capex - 维持性 capex（对应新建产能）
   - 扩张期 FCF 可能为负，成熟期 FCF 转正

4. **FCF 计算：**
   - FCF = EBIT × (1 - 税率) + 折旧 - 维持性 capex - 营运资本变动 - 扩张性 capex

**关键假设及建议范围：**

| 参数 | 含义 | 建议取值方式 |
|------|------|------------|
| 显式预测期 N | 含产能扩张周期 | 5-10年（需覆盖至少一个完整扩产周期） |
| 产能增速 | 扩产速度 | 参考在建工程和公告 |
| 产能利用率 | 投产后达产率 | 80%-95% |
| 单价增速 | 产品提价能力 | 0%-5%（取决于差异化程度） |
| 原材料成本假设 | 毛利率核心驱动 | 周期中值（Normalized 毛利率） |
| WACC | 加权平均资本成本 | 8%-12%（制造业 beta ~1，杠杆偏高取上限） |
| 终端增长率 g_terminal | 永续增长 | 2%-3%（参考长期 GDP/通胀） |
| 终期 capex/折旧比 | 维持性投资 | 1.0-1.2（终期不再扩张） |
| 终期 ROIC | 投资回报率收敛 | 趋向 WACC 附近 |

**敏感性分析网格：**

| | WACC -1% | WACC 基准 | WACC +1% |
|------|---------|---------|---------|
| g_terminal +0.5% | | | |
| g_terminal 基准 | | | |
| g_terminal -0.5% | | | |

### 3c. 可比公司估值 —— EV/EBITDA 为主，PE/PB 为辅

**核心逻辑：** 原料加工业用 EV/EBITDA 进行同业对比（消除折旧和杠杆差异），PE/PB 作为辅助参考。

**可比公司选择逻辑：**

| 类别 | 选择标准 | 示例（酵母行业） |
|------|---------|----------------|
| 同行业直接竞争者 | 产品线最接近，原材料结构相似 | 梅花生物(600873)、中粮科技(000930) |
| 跨行业重资产加工 | 资产强度和 capex 模式可比 | 新和成(002001)、星湖科技(600866) |
| 国际可比公司 | 若有海外对标 | Lesaffre（非上市）、AB Mauri（非上市） |

> 注意：原料加工业的国际可比公司多为非上市或港股，MCP 可能无法获取数据。应注明并优先使用 A 股可比。

**估值倍数对比表模板：**

```
| 公司 | EV/EBITDA | PE(TTM) | PB(LF) | ROE | ROIC | capex/营收 | EBITDA Margin | 选择理由 |
|------|----------|---------|--------|-----|------|-----------|-------------|---------|
| | | | | | | | | |
| 行业中位数 | | | | | | | | |
| 目标公司 | | | | | | | | |
```

**估值推导：**
1. 计算可比公司 EV/EBITDA 中位数
2. 根据目标公司 ROIC 与可比公司中位数的差异，确定溢价或折价
   - ROIC 高于同业 → EV/EBITDA 溢价（资本效率更优）
   - 产能利用率低 → 折价（产能浪费）
   - 原材料成本优势 → 溢价（成本曲线位置更优）
3. 合理 EV/EBITDA × Normalized EBITDA = 隐含 EV
4. 隐含 EV - 有息负债 + 现金 = 股权价值 → 每股价值

**PE 估值辅助说明：**
- PE 估值应使用 Normalized EPS 而非当前 EPS，以避免周期失真
- 若当前处于原材料周期高点（盈利高于均值），当前 PE 偏低不代表低估
- 若当前处于原材料周期低点（盈利低于均值），当前 PE 偏高不代表高估

### 估值综合

| 方法 | 估值区间 | 权重 | 备注 |
|------|---------|------|------|
| Normalized EV/EBITDA | | | 行业首选，消除周期和折旧影响 |
| DCF | | | 长期价值，含产能建模 |
| 可比公司 | | | 市场锚点 |
| **综合估值** | | | 加权或区间取交集 |

## Step 4: 市场定价分析

### 4a. 原材料周期定位

原料加工业估值必须结合原材料周期位置判断：

- **当前原材料价格处于周期什么位置**（高位/中位/低位）
- **毛利率是否已反映原材料价格变化**（传导滞后通常 1-2 个季度）
- **未来 1-2 年原材料价格方向预判**（供需格局、库存水平）
- **当前盈利处于周期什么位置**（高于/低于/接近 Normalized 水平）

```
| 指标 | 周期高点 | 当前 | 周期低点 | 当前位置 |
|------|---------|------|---------|---------|
| 原材料价格 | | | | 高/中/低 |
| 毛利率 | | | | 高/中/低 |
| PE | | | | 高/中/低 |
| EV/EBITDA | | | | 高/中/低 |
```

> 关键判断：若原材料处于周期低点 → 毛利率高于均值 → 当前 PE 偏低 → **不宜仅凭低 PE 判断低估**，应使用 Normalized Earnings。

### 4b. 历史估值分位数

使用 `get_hist_data` 获取近 5 年日频数据，计算当前估值指标在历史区间中的分位数：

- **EV/EBITDA 历史分位**（首选指标，受周期影响小）
- PE 历史分位（注意周期失真，需结合盈利周期位置解读）
- PB 历史分位
- 股息率历史分位

```
| 指标 | 5年高 | 5年低 | 当前 | 所处分位 |
|------|------|------|------|---------|
| EV/EBITDA | | | | |
| PE | | | | |
| PB | | | | |
| 股息率 | | | | |
```

分位判断标准：偏低 <25%、合理 25%-75%、偏高 >75%。

### 4c. 反向推导市场隐含预期

用当前股价反推市场定价隐含的预期：

- **若用 EV/EBITDA 法：** 固定 Normalized EBITDA，反解市场隐含的 EV/EBITDA 倍数，与可比公司对比
- **若用 DCF：** 固定 WACC 和 g_terminal，反解市场隐含的产能增速或毛利率假设
- **若用 PE 法：** 用 Normalized EPS 反解隐含 PE，与历史区间对比
- 判断市场是否过度悲观或过度乐观，是否已充分反映原材料周期

### 4d. 同业折溢价分析

- 目标公司 EV/EBITDA 相比可比公司中位数的溢价或折价
- 结合 ROIC 差异判断折溢价是否合理（高 ROIC 应享溢价）
- 结合原材料成本优势判断折溢价（低成本位置应享溢价）
- 结合产能利用率判断折溢价（高利用率应享溢价）

## Step 5: 原料加工业特有风险清单

### 看多论点框架

选择适用的论点，用数据支撑：

1. **技术/菌种壁垒** — 核心技术/专利/菌种储备形成进入壁垒，R&D 投入持续领先于同业，产品差异化程度高
2. **产能扩张驱动增长** — 在建产能充裕，投放节奏明确，投产后收入增长确定性高，单位产能投资效率优
3. **产品结构升级** — 从大宗品向高附加值产品转型（如酵母→YE→营养品），毛利率结构性提升
4. **规模经济与成本优势** — 产能规模行业领先，单位固定成本和原材料采购成本优势
5. **全球化布局** — 海外产能/收入占比提升，分散单一市场风险，获取全球市场份额
6. **原材料周期底部** — 原材料价格处于周期低位，毛利率有望回升，盈利具备弹性
7. **环保壁垒提升** — 环保政策收紧淘汰小产能，龙头企业份额提升

### 看空论点框架

选择适用的论点，用数据支撑：

1. **原材料价格风险** — 核心原材料价格大涨将压缩毛利率，若无法转嫁至下游则利润大幅下滑
2. **产能过剩风险** — 行业扩产过快导致供大于求，产能利用率下降，单位成本上升
3. **环保合规成本** — 生产过程污染排放（废水/废气/固废），环保政策收紧增加合规成本
4. **需求周期下行** — 下游行业（食品加工、饲料、酿造等）需求放缓，销量增速下降
5. **汇率风险** — 海外收入/海外原材料采购受汇率波动影响，海外工厂面临当地政策风险
6. **技术替代风险** — 新技术/新工艺/新产品可能替代现有产品（如合成生物替代传统发酵）
7. **资本开支回报风险** — 扩产项目投产不及预期、市场需求变化导致新增产能闲置
8. **杠杆风险** — 高资本开支依赖债务融资，利率上升或融资环境收紧增加财务负担
