当用户要求研究 A 股消费品行业上市公司时激活。判断依据：

- 公司属于食品饮料、家用电器、服装纺织、日化美妆、零售、休闲食品等消费板块

## Step 1: 数据收集

消费品公司研究需要以下数据，应在研究开始时**并行调用** MCP 工具一次性获取：

| # | MCP 工具 | 参数 | 用途 |
|---|---------|------|------|
| 1 | `get_realtime_data` | `symbol=6位代码, source="eastmoney_direct"` | 当前股价、PE/PB、市值、换手率 |
| 2 | `cn-a-stock_brief` | `symbol=SH/SZ+6位代码` | 基本信息与行情补充 |
| 3 | `get_hist_data` | `symbol=6位代码, interval="day", recent_n=250, adjust="qfq", indicators_list=["SMA","MACD","BOLL","RSI"]` | 近一年走势、技术指标 |
| 4 | `get_income_statement` | `symbol=6位代码, recent_n=8` | 近8期营收、成本、费用明细 |
| 5 | `get_balance_sheet` | `symbol=6位代码, recent_n=8` | 资产结构、存货、应收/应付、现金 |
| 6 | `get_cash_flow` | `symbol=6位代码, recent_n=8` | 经营现金流、资本开支、分红 |
| 7 | `get_financial_metrics` | `symbol=6位代码, recent_n=8` | ROE/ROA/毛利率等关键指标 |
| 8 | `get_inner_trade_data` | `symbol=6位代码` | 管理层/大股东增减持信号 |
| 9 | `get_news_data` | `symbol=6位代码, recent_n=20` | 近期事件、行业政策、消费趋势 |

### 消费品公司需额外关注的字段

从三表中提取时，除通用科目外，重点关注以下消费品特有科目：

**利润表：**
- 营业收入（需拆分量价：销量 × 吨价/ASP）
- 营业成本（用于计算毛利率，反映成本转嫁能力）
- 销售费用（品牌投入、渠道费用，反映品牌力变化）
- 销售费用率趋势（费用投入效率）
- 管理费用率趋势
- 税金及附加（消费税等，啤酒/白酒行业税负较重）

**资产负债表：**
- 存货（消费品存货周转是运营效率核心指标）
- 应收账款（消费品应收极少=强渠道话语权）
- 合同负债/预收账款（经销商打款意愿，反映渠道信心）
- 现金及等价物 + 交易性金融资产（净现金储备）
- 固定资产（产能分析）

**现金流量表：**
- 销售商品收到的现金（与营收对比，检验收入质量）
- 分配股利支付的现金（分红能力与意愿）
- 购建固定资产支付的现金（资本开支/产能扩张）

## Step 2: 消费品专用财务指标

消费品公司报告必须使用以下指标体系，覆盖盈利能力、运营效率、量价拆分三个维度。

### 2a. 核心盈利指标表

| 指标 | 含义 | 健康趋势 |
|------|------|---------|
| 营业收入 | 总营收 | 稳定增长 |
| 净利润 | 归母净利润 | 稳定增长 |
| 毛利率 | (营收 - 营业成本) / 营收 | 稳定或提升（反映定价权/成本转嫁能力） |
| 净利率 | 归母净利润 / 营收 | 稳定或提升 |
| 销售费用率 | 销售费用 / 营收 | 下降=品牌力增强；上升=竞争加剧 |
| 管理费用率 | 管理费用 / 营收 | 稳定或下降 |
| ROE | 归母净利润 / 平均净资产 | >15% 为优秀 |
| 资产负债率 | 总负债 / 总资产 | 消费品通常 <40%，无息负债为主 |
| 经营现金流 | 经营活动现金流量净额 | ≥净利润（盈利质量高） |
| 自由现金流 (FCF) | 经营现金流 - 资本开支 | 持续为正且增长 |
| 分红率 | 分红总额 / 归母净利润 | 稳定或提升（成熟消费品公司 >50%） |

### 2b. 量价拆分表（消费品核心分析框架）

消费品增长驱动力来自**量（销量）**和**价（吨价/ASP）**两个维度。拆分后可判断增长质量：

- **价增量稳/价增量减** = 高端化驱动，品牌溢价提升（啤酒、白酒行业的核心逻辑）
- **量增价稳** = 市场扩张期，份额驱动
- **量价齐跌** = 行业衰退或公司竞争力下降

### 2c. 运营效率表

运营效率反映消费品公司的渠道话语力和供应链管理能力：

| 指标 | 含义 | 解读 |
|------|------|------|
| 存货周转天数 | 365 / (营业成本 / 平均存货) | 越低越好；上升=滞销风险 |
| 应收账款周转天数 | 365 / (营收 / 平均应收账款) | 消费品应极低（<5天），高=渠道话语权弱 |

| 现金循环周期 | 存货天数 + 应收天数 - 应付天数 | 负值=占用上下游资金运营 |
| 合同负债/预收款增速 | — | 正增长=经销商打款积极，渠道信心强 |

## Step 3: 估值方法

消费品公司估值**至少使用以下三种方法中的两种**交叉验证。三种全部使用更佳。

### 3a. DCF 估值 —— 消费品基准方法

**适用理由：** 消费品公司现金流稳定可预测，FCF 与净利润高度一致（轻资产、稳定营运资本），适合 DCF。

**模型选择：** 两阶段 DCF（显式预测期 + 永续期）

```
企业价值 = Σ [FCF_t / (1+WACC)^t]  (t=1..N) + [FCF_{N+1} / (WACC - g_terminal)] / (1+WACC)^N
每股价值 = (企业价值 + 净现金) / 总股本
```

**消费品 DCF 建模要点：**

1. **收入预测分解为量 × 价：**
   - 销量增速：参考行业总量增速（啤酒/乳业已进入低增长或存量阶段）+ 公司份额变化
   - 吨价/ASP 增速：参考产品结构升级趋势（高端化程度）+ 通胀传导
   - 收入增速 = (1 + 销量增速) × (1 + 吨价增速) - 1

2. **毛利率预测：**
   - 考虑原材料成本周期（大麦/铝/玻璃/包材等）
   - 考虑产品结构升级对毛利率的拉动（高端产品占比提升）

3. **费用率假设：**
   - 销售费用率：品牌成熟期趋于稳定或缓慢下降
   - 管理费用率：规模效应下趋于下降

4. **资本开支：**
   - 消费品公司资本开支通常较低（轻资产），FCF ≈ 经营现金流
   - 关注产能扩张周期对短期 FCF 的影响

**关键假设及建议范围：**

| 参数 | 含义 | 建议取值方式 |
|------|------|------------|
| 显式预测期 N | 高增长期长度 | 5-10年（成熟消费品取5年） |
| 收入增速（阶段一） | 量价拆分后综合增速 | 销量增速 0%-5% + 吨价增速 2%-6% |
| 终端增长率 g_terminal | 永续增长率 | 2%-3%（参考长期通胀/GDP） |
| WACC | 加权平均资本成本 | 7%-10%（消费品 beta 通常 <1） |
| 目标净利率 | 终端期净利率 | 参考历史趋势外推 |
| 净现金 | 现金 + 交易性金融资产 - 有息负债 | 从最新资产负债表直接计算 |

**敏感性分析网格：**

| | WACC -1% | WACC 基准 | WACC +1% |
|------|---------|---------|---------|
| g_terminal +0.5% | | | |
| g_terminal 基准 | | | |
| g_terminal -0.5% | | | |

### 3b. DDM（股息贴现模型）—— 成熟消费品首选

**适用理由：** 成熟消费品公司（如青岛啤酒、伊利股份）分红稳定、FCF 充裕、增长温和，DDM 是最贴切的估值方法之一。

**适用条件检查：**
- 分红率 >30% 且稳定
- 经营现金流持续为正且覆盖分红
- 净现金为正（无有息负债或极少）
- 收入增速进入个位数（成熟期）

**模型选择：** 两阶段 DDM

```
每股内在价值 = Σ [DPS_t / (1+r)^t]  (t=1..N) + [DPS_{N+1} / (r - g_terminal)] / (1+r)^N
```

**关键假设及建议范围：**

| 参数 | 含义 | 建议取值方式 |
|------|------|------------|
| 当前 DPS | 最近12个月每股分红 | 从现金流量表"分配股利支付的现金" / 总股本 |
| 阶段一增长率 g1 | 高速增长期股息增长率 | 取近3-5年分红CAGR，适当下调 |
| 阶段一年限 N | 高速增长期长度 | 5年 |
| 终端增长率 g_terminal | 永续增长率 | 2%-3%（参考长期GDP/通胀） |
| 股权成本 r (COE) | 折现率 | 7%-10%（用 CAPM 估算，消费品 beta <1） |

**敏感性分析网格：**

| | COE -1% | COE 基准 | COE +1% |
|------|---------|---------|---------|
| g_terminal +0.5% | | | |
| g_terminal 基准 | | | |
| g_terminal -0.5% | | | |

### 3c. 可比公司估值

**核心逻辑：** 消费品公司用 PE/PS/EV/EBITDA 进行同业对比，结合增长率和 ROE 差异判断折溢价。

**可比公司选择逻辑：**

| 类别 | 选择标准 | 示例（啤酒行业） |
|------|---------|----------------|
| 直接竞争对手 | 同细分行业、同市场 | 燕京啤酒(000729)、重庆啤酒(600132)、珠江啤酒(002461) |
| 跨市场可比 | 同行业港股/海外 | 华润啤酒(00291.HK)、百威亚太(01876.HK) |
| 大消费可比 | 相同消费场景/渠道 | 重庆啤酒(600132) |

> 注意：港股/海外可比公司需额外获取数据，若 MCP 不支持则注明并仅使用 A 股可比。

**估值倍数对比表模板：**

```
| 公司 | PE(TTM) | PB(LF) | PS(TTM) | EV/EBITDA | ROE | 营收增速 |
|------|---------|--------|---------|-----------|-----|---------|
| 燕京啤酒 | | | | | | |
| 重庆啤酒 | | | | | | |
| 珠江啤酒 | | | | | | |
| 华润啤酒(HK) | | | | | | |
| 行业中位数 | | | | | | |
| 目标公司 | | | | | | |
```

**估值推导：**
1. 计算可比公司 PE/PS/EV-EBITDA 中位数
2. 根据目标公司增长率/ROE 与可比公司中位数的差异，确定溢价或折价
3. 合理 PE × EPS = 合理股价（或合理 PS × 营收 / 总股本 = 合理股价）

## Step 4: 市场定价分析

### 历史估值分位数

使用 `get_hist_data` 获取近5年/10年日频数据，计算当前 PE/PB/PS/股息率在历史区间中的分位数：

- 当前 PE / PB / PS / 股息率
- 5年历史分位数（偏低 <25%、合理 25%-75%、偏高 >75%）
- 10年历史分位数

### 反向推导市场隐含预期

用当前股价反推市场定价隐含的增长预期：

- **若用 DDM：** 固定 COE 和 g_terminal，反解 g1，与实际增速对比
- **若用 DCF：** 固定 WACC 和 g_terminal，反解隐含收入增速，与量价拆分后的实际增速对比
- **若用 PE 法：** 合理 PE = (1+g) / (r - g) × (1 - 分红率) + 分红率，反解隐含 g
- 判断市场是否过度悲观或过度乐观

### 同业折溢价分析

- 目标公司 PE/PS 相比可比公司均值/中位数的溢价或折价
- 结合 ROE/营收增速差异判断折溢价是否合理（高 ROE/高增长应享溢价）
- 消费品溢价来源：品牌力（毛利率高低）、渠道力（周转效率）、产品结构（高端化程度）

## Step 5: 消费品特有风险清单

### 看多论点框架

选择适用的论点，用数据支撑：

1. **品牌溢价提升（高端化）** — 高端产品占比提升、吨价/ASP 持续增长、毛利率提升趋势
2. **渠道话语权** — 应收账款极低、合同负债/预收款增长、现金循环周期为负
3. **成本转嫁能力** — 毛利率在原材料涨价周期中保持稳定或提升
4. **现金牛属性** — 经营现金流持续为正且 ≥净利润、FCF 充裕、净现金储备大
5. **分红回报** — 分红率稳定/提升、股息率具有吸引力
6. **份额整合** — 行业集中度提升、中小品牌退出、龙头份额增长
7. **效率提升** — 销售费用率下降、管理费用率下降、存货周转加快

### 看空论点框架

选择适用的论点，用数据支撑：

1. **行业见顶/销量下滑** — 行业总销量增速放缓或转负、人口结构变化（老龄化、年轻人饮酒量下降）
2. **消费降级** — 高端产品增速放缓、吨价增速回落、消费者转向性价比产品
3. **成本上行** — 原材料（大麦/大米/铝/玻璃/包材）价格周期上行、毛利率承压
4. **竞争加剧** — 销售费用率上升、促销/折扣增加、新进入者搅动市场
5. **渠道变革** — 即饮/餐饮渠道萎缩、电商/新零售冲击传统渠道、渠道利润被压缩
6. **政策风险** — 消费税改革（从生产环节后移至批发/零售环节）、健康政策（控酒/控糖）、广告限制
7. **增长天花板** — 人均消费量已达发达国家水平、高端化空间收窄

```
reports/{公司简称}/
  report.md          # 主研究报告（基于 templates/valuation-report-consumer.md 模板）
  data/              # 支撑数据与计算
```

**报告适配要求：**
- 使用 `templates/valuation-report-consumer.md` 作为起点（而非通用模板）
- 财务指标表使用本 skill Step 2 的消费品专用指标表
- 估值分析使用 Step 3 的三种方法中至少两种
- 风险因素使用 Step 5 的多空框架
- 品牌与产品结构分析使用 Step 6 的框架
- 所有数据引用标注来源和日期
- 销量/吨价等非报表数据若无法通过 MCP 获取，应注明"需从年报正文获取"并提醒用户
