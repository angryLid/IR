## When to Use

当用户要求研究 A 股电力/公用事业行业上市公司时激活。判断依据：

- 公司属于火电、水电、核电、风电、光伏、燃气发电等发电业务为主的企业
- 公司名称包含"电力""能源""发电""水电""核电"等关键词
- 用户明确提及"电力股""公用事业""电力行业"并要求估值研究
- 股票代码对应申万行业分类：公用事业（电力、燃气）

本 skill 补充 AGENTS.md 通用研究规范中**电力/公用事业行业特有的处理逻辑**。通用规则（数据来源优先级、报告目录结构、免责声明等）仍遵循 AGENTS.md。

### 电力公司需额外关注的字段

从三表中提取时，除通用科目外，重点关注以下电力行业特有科目：

**利润表：**
- 营业收入（需拆分为：上网电量 × 上网电价）
- 营业成本（燃料费/水资源费/折旧/人工的拆分是度电成本分析基础）
- 税金及附加（含水资源税、环保税等）
- 财务费用（高杠杆下利息支出是利润敏感变量）
- 投资收益（参股电站/其他发电企业带来的收益，电力公司常见）

**资产负债表：**
- 固定资产（电站资产，反映装机规模与折旧基础）
- 在建工程（新投产/在建机组，反映未来产能增长）
- 长期借款 + 短期借款 + 应付债券（有息负债总额，反映杠杆水平）
- 少数股东权益（电力公司常为控股型架构，少数股东权益占比高）

**现金流量表：**
- 销售商品收到的现金（与营收对比，电力公司回款质量通常较高）
- 购建固定资产支付的现金（资本开支，关注新机组/新能源投资周期）
- 分配股利支付的现金（分红能力与意愿）
- 取得借款收到的现金 / 偿还债务支付的现金（借新还旧规模）

> **装机结构、利用小时、上网电价等运营数据**通常不在标准财务报表中，需从年报"经营情况讨论与分析"章节获取。若 MCP 工具无法获取，应在报告中注明数据来源（年报页码）并提醒用户。

## Step 2: 电力行业专用财务指标

电力公司报告必须使用以下指标体系，覆盖盈利能力、运营效率、装机与发电量三个维度。

### 2a. 核心盈利指标表

| 指标 | 含义 | 健康趋势 |
|------|------|---------|
| 营业收入 | 上网电量 × 上网电价 | 稳定增长 |
| 净利润 | 归母净利润 | 稳定增长（注意少数股东损益占比） |
| 毛利率 | (营收 - 营业成本) / 营收 | 水电 >50% 为优秀；火电受燃料价格周期影响大 |
| 净利率 | 归母净利润 / 营收 | 水电 >25% 为优秀；火电 5%-15% |
| ROE | 归母净利润 / 平均净资产 | >12% 为优秀 |
| ROA | 归母净利润 / 平均总资产 | >3% 为优秀（资产重，ROA 基数低） |
| 资产负债率 | 总负债 / 总资产 | 60%-75% 为常态，过高 >80% 关注偿债风险 |
| 利息保障倍数 | EBIT / 利息费用 | >3 为安全 |
| 经营现金流 | 经营活动现金流量净额 | 持续为正，通常 >>净利润（折旧大） |
| FCF | 经营现金流 - 资本开支 | 投产期可为负，稳定期为大额正数 |

| 股息率 | 每股分红 / 股价 | 与可比公司及无风险利率对比 |

## Step 3: 估值方法

电力公司估值**至少使用以下三种方法中的两种**交叉验证。三种全部使用更佳。

### 3a. DCF 估值 —— 电力基准方法

**适用理由：** 电力资产寿命长（水电 30-50 年，火电 20-30 年），现金流相对稳定可预测，适合用 FCF 贴现反映长期价值。

**模型选择：** 两阶段 DCF（显式预测期 + 永续期）

```
企业价值 = Σ [FCF_t / (1+WACC)^t]  (t=1..N) + [FCF_{N+1} / (WACC - g_terminal)] / (1+WACC)^N
每股价值 = (企业价值 - 净负债) / 总股本
```

> 注意：电力公司通常净负债为正（有息负债 > 现金），与消费品公司相反。

**电力 DCF 建模要点：**

1. **收入预测分解为量 × 价：**
   - 上网电量 = 装机容量 × 利用小时 × (1 - 厂用电率)
   - 利用小时假设：水电参考历史来水周期均值；火电参考电力供需平衡预测
   - 上网电价假设：考虑市场化交易比例提升趋势、煤电价格联动机制
   - 新增装机：从在建工程和公告中提取未来投产计划

2. **成本预测：**
   - 燃料成本（火电）：参考煤价/气价周期，关注长协煤比例
   - 折旧：基于固定资产余额和折旧政策，新增投产后折旧增加
   - 水资源费/环保税：与发电量线性相关

3. **资本开支：**
   - 电力公司资本开支周期性强（新建机组期高、投产后低）
   - 关注在建工程转固节奏
   - 新能源转型投资（风电/光伏）是未来 capex 重要变量

4. **WACC 计算：**
   - 电力公司杠杆高，债务权重通常 60%-70%
   - 税后债务成本参考实际利息支出 / 有息负债
   - 注意不同电源类型的风险差异（水电 beta 低、火电 beta 高）

**关键假设及建议范围：**

| 参数 | 含义 | 建议取值方式 |
|------|------|------------|
| 显式预测期 N | 高增长期长度 | 5-10年（参考在建工程投产周期） |
| 利用小时假设 | 各电源类型利用小时 | 水电取历史5年均值；火电参考区域供需 |
| 电价假设 | 上网电价趋势 | 考虑市场化交易比例提升的下行压力 |
| 终端增长率 g_terminal | 永续增长率 | 1.5%-3%（电力需求增速趋缓） |
| WACC | 加权平均资本成本 | 6%-9%（高杠杆降低 WACC，但股权风险仍存在） |
| 终期 capex/折旧比 | 维持性投资比例 | 70%-90%（电力资产长期需更新投资） |

**敏感性分析网格：**

| | WACC -1% | WACC 基准 | WACC +1% |
|------|---------|---------|---------|
| g_terminal +0.5% | | | |
| g_terminal 基准 | | | |
| g_terminal -0.5% | | | |

### 3b. DDM（股息贴现模型）—— 电力央企适用

**适用理由：** 电力央企（国投电力、长江电力等）通常有稳定分红政策，经营现金流充沛支撑分红可持续性。

**适用条件检查：**
- 分红率 >30% 且近3年稳定
- 经营现金流持续为正且覆盖分红
- 处于相对稳定运营期（无大规模在建工程导致资本开支激增）
- 央企/国企背景，分红政策透明

**模型选择：** 两阶段 DDM

```
每股内在价值 = Σ [DPS_t / (1+r)^t]  (t=1..N) + [DPS_{N+1} / (r - g_terminal)] / (1+r)^N
```

**关键假设及建议范围：**

| 参数 | 含义 | 建议取值方式 |
|------|------|------------|
| 当前 DPS | 最近12个月每股分红 | 从现金流量表"分配股利支付的现金" / 总股本 |
| 阶段一增长率 g1 | 高速增长期股息增长率 | 取近3-5年分红CAGR，考虑装机增长与电价趋势 |
| 阶段一年限 N | 高速增长期长度 | 5年（参考在建工程投产周期） |
| 终端增长率 g_terminal | 永续增长率 | 1.5%-3%（参考长期电力需求增速） |
| 股权成本 r (COE) | 折现率 | 7%-10%（用 CAPM 估算） |

**敏感性分析网格：**

| | COE -1% | COE 基准 | COE +1% |
|------|---------|---------|---------|
| g_terminal +0.5% | | | |
| g_terminal 基准 | | | |
| g_terminal -0.5% | | | |

### 3c. 可比公司估值（EV/EBITDA 为核心）

**核心逻辑：** 电力公司因杠杆水平、折旧政策差异大，PE 和 PB 可比性差。EV/EBITDA 消除杠杆和折旧差异，是电力行业最优可比倍数。

**可比公司选择逻辑：**

| 类别 | 选择标准 | 示例 |
|------|---------|------|
| 同电源类型 | 相同发电类型为主 | 水电：长江电力(600900)、川投能源(600674)；火电：华能国际(600011)、华电国际(600027) |
| 综合电力 | 水火并举 | 国电电力(600795)、华能国际(600011) |
| 同区域 | 相同电力市场 | 同区域公司利用小时、电价可比性强 |

**估值倍数对比表模板：**

```
| 公司 | EV/EBITDA | PE(TTM) | PB(LF) | ROE | 股息率 | 装机(GW) | 水电占比 |
|------|-----------|---------|--------|-----|--------|---------|---------|
| 长江电力 | | | | | | | |
| 国电电力 | | | | | | | |
| 华能国际 | | | | | | | |
| 川投能源 | | | | | | | |
| 行业中位数 | | | | | | | |
| 目标公司 | | | | | | | |
```

**估值推导：**
1. 计算可比公司 EV/EBITDA 中位数
2. 根据目标公司电源结构（水电占比越高估值越高）、ROE、增长潜力确定溢价或折价
3. 合理 EV/EBITDA × EBITDA = 企业价值
4. 企业价值 - 净负债 = 股权价值
5. 股权价值 / 总股本 = 合理股价

**EV/EBITDA 折溢价判断要素：**

| 要素 | 溢价方向 | 逻辑 |
|------|---------|------|
| 水电占比 | 水电占比高 → 溢价 | 水电成本低、现金流稳、无燃料价格风险 |
| 利用小时 | 利用小时高 → 溢价 | 反映资产质量和需求旺盛 |
| 资产负债率 | 杠杆低 → 溢价 | 财务风险低 |
| 分红率 | 分红率高 → 溢价 | 回报确定性强 |
| 增长潜力 | 在建/规划装机多 → 溢价 | 未来增长可见 |

| 方法 | 估值区间 | 权重 | 备注 |
|------|---------|------|------|
| DCF | | | 基准方法，反映长期资产价值 |
| DDM | | | 适用于稳定分红期 |
| 可比公司 EV/EBITDA | | | 市场锚点 |
| **综合估值** | | | 加权或区间取交集 |

## Step 4: 市场定价分析

### 历史估值分位数

使用 `get_hist_data` 获取近5年/10年日频数据，计算当前 PE/PB/EV-EBITDA/股息率在历史区间中的分位数：

- 当前 PE / PB / EV-EBITDA / 股息率
- 5年历史分位数（偏低 <25%、合理 25%-75%、偏高 >75%）
- 10年历史分位数

### 反向推导市场隐含预期

用当前股价反推市场定价隐含的增长预期：

- **若用 DDM：** 固定 COE 和 g_terminal，反解 g1，与实际分红增速对比
- **若用 DCF：** 固定 WACC 和 g_terminal，反解隐含利用小时或电价，与当前水平对比
- **若用 EV/EBITDA：** 计算当前 EV/EBITDA 隐含的 EBITDA 增长率，与历史增速对比
- 判断市场是否过度悲观或过度乐观

### 同业折溢价分析

- 目标公司 EV/EBITDA 相比可比公司均值/中位数的溢价或折价
- 结合水电占比、ROE、利用小时差异判断折溢价是否合理
- 电力公司溢价来源：水电占比高、利用小时高、杠杆低、分红率高

## Step 5: 电力行业特有风险清单

### 看多论点框架

选择适用的论点，用数据支撑：

1. **水电核心资产价值** — 水电占比高、利用小时稳定、度电成本低、无燃料价格风险、现金流可预测
2. **装机增长可见** — 在建工程/规划装机明确、未来发电量增长确定性强
3. **电价市场化机遇** — 市场化交易占比提升中灵活定价能力、水电享有绿色溢价
4. **成本优势** — 度电成本低于同业、燃料成本占比低（水电）、折旧已充分（老机组）
5. **现金流与分红** — 经营现金流 >>净利润、分红率稳定提升、股息率具吸引力
6. **新能源转型** — 风电/光伏装机增长、受益于双碳政策、绿电交易溢价
7. **财务杠杆下降** — 进入还款期、资产负债率下降、利息支出减少、利润弹性释放

### 看空论点框架

选择适用的论点，用数据支撑：

1. **来水波动风险** — 水电利用小时受降水周期影响大、枯水年业绩大幅下滑
2. **电价下行压力** — 市场化交易比例提升导致上网电价下行、电力市场化改革深化
3. **燃料成本上行** — 煤价/气价上涨周期中火电盈利大幅压缩、长协煤覆盖不足
4. **利用小时下降** — 电力供给过剩（新能源大量投产挤压火电）、区域电力需求增长放缓
5. **高杠杆风险** — 资产负债率 >80%、利息支出侵蚀利润、偿债压力大
6. **资本开支周期** — 大规模在建工程导致 FCF 为负、融资需求增加、分红能力受限
7. **环保与政策风险** — 碳排放成本上升（火电）、环保改造投入、水资源税调整
8. **少数股东权益侵蚀** — 控股型架构下少数股东损益占比高、归母净利润被摊薄
