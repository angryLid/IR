## When to Use

当用户要求研究 A 股银行业上市公司时激活。判断依据：

- 公司名称包含"银行"（如招商银行、平安银行、宁波银行、工商银行等）
- 用户明确提及"银行股""银行业"并要求估值研究
- 股票代码对应银行业分类

本 skill 补充 AGENTS.md 通用研究规范中**银行行业特有的处理逻辑**。通用规则（数据来源优先级、报告目录结构、免责声明等）仍遵循 AGENTS.md。

## Step 1: 数据收集

银行股研究需要以下数据，应在研究开始时**并行调用** MCP 工具一次性获取：

| # | MCP 工具 | 参数 | 用途 |
|---|---------|------|------|
| 1 | `get_realtime_data` | `symbol=6位代码, source="eastmoney_direct"` | 当前股价、PE/PB、市值、换手率 |
| 2 | `cn-a-stock_brief` | `symbol=SH/SZ+6位代码` | 基本信息与行情补充 |
| 3 | `get_hist_data` | `symbol=6位代码, interval="day", recent_n=250, adjust="qfq", indicators_list=["SMA","MACD","BOLL","RSI"]` | 近一年走势、技术指标 |
| 4 | `get_income_statement` | `symbol=6位代码, recent_n=8` | 近8期营收、净利润、非息收入明细 |
| 5 | `get_balance_sheet` | `symbol=6位代码, recent_n=8` | 资产规模、存贷款结构、股东权益、资本充足率 |
| 6 | `get_cash_flow` | `symbol=6位代码, recent_n=8` | 经营现金流、分红能力 |
| 7 | `get_financial_metrics` | `symbol=6位代码, recent_n=8` | ROE/ROA/NIM/不良率等关键指标 |
| 8 | `get_inner_trade_data` | `symbol=6位代码` | 管理层/大股东增减持信号 |
| 9 | `get_news_data` | `symbol=6位代码, recent_n=20` | 近期事件、政策影响 |

### 银行股需额外关注的字段

从三表中提取时，除通用科目外，重点关注以下银行特有科目：

**利润表：**
- 利息净收入（含利息收入、利息支出）
- 手续费及佣金净收入（非息收入核心）
- 投资收益（非息收入另一来源）
- 信用减值损失（资产质量的风向标）

**资产负债表：**
- 发放贷款及垫款总额与净额
- 客户存款总额
- 同业资产/负债
- 交易性金融资产
- 贷款损失准备余额

**现金流量表：**
- 吸收存款净增加额
- 发放贷款净增加额
- 分配股利支付的现金

## Step 2: 银行专用财务指标

通用模板中的毛利率、自由现金流(FCF)等指标**不适用于银行**。银行股报告必须使用以下指标替代：

| 指标 | 含义 | 健康趋势 |
|------|------|---------|
| 营业收入 | 利息净收入 + 非息收入 | 稳定增长 |
| 净利润 | 归母净利润 | 稳定增长 |
| 净息差 (NIM) | 利息净收入 / 平均生息资产 | 关注趋势方向 |
| 不良贷款率 (NPL) | 不良贷款 / 贷款总额 | 越低越好，关注趋势 |
| 拨备覆盖率 | 贷款减值准备 / 不良贷款 | >150% 为安全 |
| ROE | 归母净利润 / 平均净资产 | >12% 为优秀 |
| ROA | 归母净利润 / 平均总资产 | >0.8% 为优秀 |
| 资本充足率 (CAR) | 资本净额 / 风险加权资产 | 满足监管要求(≥10.5%) |
| 一级资本充足率 | 一级资本 / 风险加权资产 | 满足监管要求(≥8.5%) |
| 成本收入比 | 业务及管理费 / 营业收入 | 越低越好 |
| 存贷比 | 贷款总额 / 存款总额 | 80%-100% 为常态 |
| 非息收入占比 | 非息收入 / 营业收入 | 越高越好，体现轻资本转型 |
| 股息率 | 每股分红 / 股价 | 与可比公司对比 |

在报告中使用以下表格模板（至少覆盖近4年/8个报告期）：

```
| 指标 | FY-3 | FY-2 | FY-1 | FY0 | 趋势 |
|------|------|------|------|-----|------|
| 营业收入（亿元） | | | | | |
| 净利润（亿元） | | | | | |
| NIM | | | | | |
| 不良贷款率 | | | | | |
| 拨备覆盖率 | | | | | |
| ROE | | | | | |
| ROA | | | | | |
| 资本充足率 | | | | | |
| 成本收入比 | | | | | |
| 非息收入占比 | | | | | |
| 股息率 | | | | | |
```

## Step 3: 估值方法

银行股估值**至少使用以下三种方法中的两种**交叉验证。三种全部使用更佳。

### 3a. DDM（股息贴现模型）—— 银行首选

**适用理由：** 银行分红稳定且可预测，现金流以股息形式回馈股东，是银行股最贴切的估值方法。

**模型选择：** 两阶段 DDM

```
每股内在价值 = Σ [DPS_t / (1+r)^t]  (t=1..N) + [DPS_{N+1} / (r - g_terminal)] / (1+r)^N
```

**关键假设及建议范围：**

| 参数 | 含义 | 建议取值方式 |
|------|------|------------|
| 阶段一增长率 g1 | 高速增长期股息增长率 | 取近3-5年分红CAGR，适当下调 |
| 阶段一年限 N | 高速增长期长度 | 5年 |
| 终端增长率 g_terminal | 永续增长率 | 2%-4%（参考长期GDP增速） |
| 股权成本 r (COE) | 折现率 | 8%-11%（用 CAPM 估算） |

**敏感性分析网格：**

| | COE -1% | COE 基准 | COE +1% |
|------|---------|---------|---------|
| g_terminal +0.5% | | | |
| g_terminal 基准 | | | |
| g_terminal -0.5% | | | |

### 3b. PB + ROE 联动法

**核心逻辑：** 银行以净资产为经营基础，PB 是最常用的银行估值倍数。理论上合理 PB ≈ ROE / COE，高 ROE 银行享有 PB 溢价。

**可比公司选择逻辑：**

| 类别 | 代表公司 | 选择理由 |
|------|---------|---------|
| 国有大行 | 工商银行(601398)、建设银行(601939) | 规模对标、系统性估值基准 |
| 股份行 | 平安银行(000001)、兴业银行(601166)、中信银行(601998) | 业务模式最可比 |
| 优质城商行 | 宁波银行(002142)、成都银行(601838) | 高 ROE 对标，观察溢价水平 |

**估值倍数对比表模板：**

```
| 公司 | PE(TTM) | PB(LF) | ROE | 股息率 | 总资产(万亿) |
|------|---------|--------|-----|--------|-------------|
| 工商银行 | | | | | |
| 建设银行 | | | | | |
| 平安银行 | | | | | |
| 兴业银行 | | | | | |
| 宁波银行 | | | | | |
| 目标公司 | | | | | |
```

**估值推导：**
1. 计算可比公司 PB / ROE 比值，得出行业均衡倍数
2. 用目标公司 ROE × 均衡倍数 = 合理 PB
3. 合理 PB × 每股净资产 = 合理股价

### 3c. 剩余收益模型 (RIM)

**适用理由：** 以账面价值为起点，对 ROE 超过 COE 的部分折现，对银行尤为贴切，可验证 DDM 结果。

**公式：**

```
每股内在价值 = BPS_0 + Σ [ (ROE_t - r) × BPS_{t-1} / (1+r)^t ]  (t=1..N)
             + [ (ROE_terminal - r) × BPS_N / (r - g_terminal) ] / (1+r)^N
```

**关键假设：**
- 未来 ROE 逐步收敛至 COE 附近（竞争使超额回报消减）
- 终端阶段 ROE_terminal 取 10%-12%
- 其余参数与 DDM 保持一致以便交叉验证

**计算步骤：**
1. 取最新每股净资产 BPS_0
2. 预测未来5年 ROE 和 BPS 增长路径
3. 计算各期剩余收益并折现
4. 计算终端剩余收益并折现
5. 汇总得出内在价值

## Step 4: 市场定价分析

### 历史估值分位数

使用 `get_hist_data` 获取近5年/10年日频数据，计算当前 PE/PB/股息率在历史区间中的分位数：

- 当前 PE / PB / 股息率
- 5年历史分位数（偏低 <25%、合理 25%-75%、偏高 >75%）
- 10年历史分位数

### 反向推导市场隐含预期

用当前股价反推市场定价隐含的增长预期：

- 若用 DDM：固定 COE 和 g_terminal，反解 g1，与实际增速对比
- 若用 PB 法：固定 COE，反解隐含 ROE，与实际 ROE 对比
- 判断市场是否过度悲观或过度乐观

### 同业折溢价分析

- 目标公司 PB/PE 相比可比公司均值/中位数的溢价或折价
- 结合 ROE 差异判断折溢价是否合理（高 ROE 应享溢价）

## Step 5: 银行特有风险清单

### 看多论点框架

选择适用的论点，用数据支撑：

1. **零售业务护城河** — AUM 规模及增速、零售客户数、零售贷款占比、零售业务利润贡献度
2. **资产质量优势** — NPL 低于同业、拨备覆盖率充足、关注类贷款占比低、逾期90天以上贷款/不良贷款比值
3. **盈利能力领先** — ROE/ROA 持续高于同业、NIM 韧性、非息收入占比提升
4. **分红回报** — 派息率稳定、股息率高于无风险利率
5. **资本充足** — CAR 充裕、无需频繁融资
6. **轻资本转型** — 手续费及佣金收入占比提升、成本收入比下降

### 看空论点框架

选择适用的论点，用数据支撑：

1. **NIM 收窄** — LPR 下行、存款定期化趋势、资产端收益率下降快于负债端成本下降
2. **房地产敞口** — 对公房地产贷款占比、涉房贷款不良率、房地产相关非标投资
3. **城投债务风险** — 城投相关贷款/投资占比、区域集中度
4. **宏观经济放缓** — 信贷需求走弱、居民消费信贷增速放缓、企业经营贷资产质量
5. **资本约束** — 资本充足率接近监管红线、再融资稀释风险
6. **金融监管收紧** — 系统重要性银行附加资本要求、让利实体经济政策
