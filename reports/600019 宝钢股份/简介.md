# 宝钢股份（600019）公司简介

> 报告日期：2026-08-24

## 公司概况

宝山钢铁股份有限公司（简称"宝钢股份"，600019.SH）是全球领先的现代化钢铁联合企业，总部位于上海，是中国宝武钢铁集团的核心上市平台，也是中国乃至全球规模最大、产品结构最高端的上市钢企之一。公司粗钢产能约 4700 万吨/年，居全球前列，产品覆盖汽车板、电工钢、镀锡板、宽厚板等高端钢材，是国内少数能大规模稳定供应汽车外板、取向硅钢等"卡脖子"品种的钢厂。

## 主营构成与商业模式

| 维度 | 说明 |
|------|------|
| 产品结构 | 以高端板材为主（汽车板、电工钢、镀锡板、宽厚板、热轧/冷轧板卷），长材为辅；高端产品占比显著高于行业平均 |
| 商业模式 | 大宗商品制造，盈利 = 钢材售价 − 原材料成本（以铁矿石、焦炭为核心输入）为核心；但依托高端产品结构，销售溢价与盈利稳定性优于普钢 |
| 下游行业 | 汽车、家电、电力设备、机械、造船、建筑地产（长材与部分板材） |
| 产业链位置 | 中游（铁矿/焦煤采选—冶炼—轧制—深加工），上游为全球铁矿石与焦煤供应商，下游为制造业与建筑业 |
| 市场地位 | 全球粗钢产能第一梯队、国内高端板材龙头；获母公司中国宝武协同支持，技术与管理领先，是行业盈利标杆 |

## 行业判定

宝钢股份属于**钢铁行业（普钢/高级板材）**。现有研究 skill 覆盖银行、消费品、电力、原料加工四类，**钢铁行业无直接匹配 skill**。钢铁企业强周期、重资产、产品同质化（虽宝钢高端化降低弹性），盈利随钢价与矿价剧烈波动，ROE 从峰到谷差距十倍以上——适用**周期平均法（Cyclical Earnings Normalization，见 `methodology/cyclical-earnings-normalization.md`）**进行估值，即识别完整盈利周期、计算正常化盈利、再乘行业正常化倍数，而非直接以单年盈利估值。

本项目采用「提议 → 确认 → 执行」引导模式，研究方向聚焦于**周期识别与周期平均法估值**。当前已完成 Step 1 周期识别与 Step 2 正常化盈利（悲观情景）的初步计算，详见 `report.md`。
