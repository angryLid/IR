## 摘要（当前判断 · EBITDA 口径修正版）

在**悲观情景**（地产需求中枢不可逆下移，以 2022-2025 为下一周期正常中枢）下：

- 悲观正常化盈利：**EPS ≈ 0.478 元 / ROE ≈ 5.23% / EBIT ≈ 151 亿 / EBITDA ≈ 342.8 亿**
- 当前总市值 ≈ **1276 亿**，EV ≈ **1508 亿**，现价 **5.86 元**
- 合理价区间（悲观 Normalized EBITDA × 钢铁 5-7x）：**约 6.8 ~ 10.0 元**；PE 路线约 3.8 ~ 5.7 元
- 当前隐含 EV/EBITDA = **4.4x**（低于钢铁正常化 5-7x 区间下沿）、隐含 PE = 12.3x
- **综合判断（悲观情景）**：EBITDA 口径看**偏便宜或合理**（当前隐含 4.4x 低于 5-7x）；PE 口径看当前 12.3x 处于中性 PE 上沿。**结论取决于以 EBITDA 还是 PE 为主锚，且高度依赖情景设定。**

> ⚠️ 以上为**悲观情景**结论。若乐观情景成立（地产企稳、宝钢高端化+出口对冲），正常化盈利将更高、合理价上移。**"贵/便宜"依赖情景与口径，本文档为中间产物，非最终投资结论。**

## 1. 周期识别

### 1.1 数据来源与口径

财务数据取自 `analysis_codes/data/financial/` 下新浪财经三大报表 CSV（单位：万元），覆盖 **2014-2025 年报**，另含 2015-2025 现金流量表（折旧摊销）。计算脚本：
- `analysis_codes/identify_cycle.py` → 逐年盈利序列 → `data/derived/annual_earnings_series.json`
- `analysis_codes/exogenous_cycle_evidence.py` → 外生周期证据
- `analysis_codes/normalized_pessimistic_A.py` → 悲观正常化（EBIT 口径）
- `analysis_codes/ebitda_series.py` → 逐年 EBITDA 序列（含折旧摊销）→ `data/derived/ebitda_series.json`

**关键口径**（方法论 §3.1）：
- EBIT（近似）= 营业利润 + 财务费用（免费源不拆分利息明细，方向保守，略低估）
- EBITDA = EBIT + 折旧摊销（固定资产折旧 + 无形资产摊销 + 长期待摊费用摊销；新浪免费页未见使用权资产折旧单列，按 0 并披露）
- ROE = 归母净利润 ÷ 归母净资产
- 期货数据为**主力连续免费替代**（新浪主连），仅用于方向/分位辅助，不代表当期钢厂毛利

**数据缺口与处理（2026-08-24 披露）**：新浪现金流量表在 2022（年报列）与 2023（全年）缺失"固定资产折旧"行，已重抓验证为源数据缺陷。因宝钢该科目历年稳定在 ~190 亿（2017-2025 同量级），**经用户确认，对 2022/2023 用相邻有值年份线性插补**，并在 `ebitda_series.json` 中 `da_interpolated=True` 标记。插补值 184.5/185.0 亿与真实值一致（2021:183.9、2024:185.6）。

**关键观察（为什么 EBITDA/EBIT 比重要）**：宝钢 EBITDA 利润率（9-17%）显著高于 EBIT 利润率（3-11%），因钢铁为高折旧重资产，折旧摊销每年约 190-190 亿（2017-2025 稳定）。**因此用 EBIT 配 EV/EBITDA 倍数会严重低估盈利基数。**

### 1.3 完整周期判定（用户确认）

采用**双周期框架**（用户指定思路）：
- **上一完整周期 = 2015-2021**：谷底（2015/16）→ 顶点（2021），波形完整，作为基准周期。
- **下一周期 = 2022 起**：总体弱于上一周期。

**外生证据（避免循环论证）：**
1. **盈利本身**：波形完整，峰谷 ROE 0.9%→12.4%(≈14 倍)、EPS 0.06→1.07(≈18 倍)。✓
2. **行业价格（期货主连，方向/分位）**：RB 价 2015 年 7% 分位 → 2021 年 94% 分位 → 2025 年 29%；RB 价差同步 2015 谷底(13) → 2021 顶(85) → 2025 底(16)。✓
3. **宏观需求（核心外生证据）**：地产新开工累计同比 2016-2019 正增长(+8%~+17%) → **2022 起连续 4 年深跌（-39%、-20%、-23%、-20%）**。✓
4. **统计工具**：盈利与价格/需求拐点（2015 谷、2021 顶）相互印证。✓

**结构性判断（用户确认）**：地产需求中枢下移判定为**不可逆的结构性下移**，下一周期正常化不能沿用上一周期中枢，需施加"下移"修正。

## 2. 正常化盈利计算

### 2.1 框架

$$\text{Normalized(下一周期)} = \text{Normalized(基准周期 2015-2021)} \times (1 - \delta)$$

δ 由 2022-2025 已发生数据校准。当 δ = 1 − (下周期均值/基准均值) 时上式恒等于 2022-2025 直接均值（数学恒等）。

### 2.2 基准周期正常化（2015-2021，简单平均）

| 指标 | 基准均值(2015-2021) |
|------|--------------------|
| Normalized EPS | 0.663 元 |
| Normalized ROE | 8.34% |
| Normalized EBIT | 213.7 亿 |
| Normalized EBITDA | 380.8 亿 |

### 2.3 悲观情景正常化（方法 A：2022-2025 均值）

| 指标 | 悲观 Normalized（2022-2025 均值） | 相对基准下移 δ |
|------|----------------------------------|----------------|
| **Normalized EPS** | **0.478 元** | -28% |
| **Normalized ROE** | **5.23%** | -37% |
| **Normalized EBIT** | **151.0 亿** | -29% |
| **Normalized EBITDA** | **342.8 亿** | **-10%** |
| Normalized EBIT利润率 | 4.45% | -41% |
| Normalized EBITDA利润率 | 10.15% | — |

**重要**：EBITDA 的下移幅度（-10%）远小于 EBIT（-29%），因为折旧摊销（反映存量产能，不随当前盈利大幅波动）在周期下行期充当了"盈利缓冲垫"，使 EBITDA 相对稳定。这也从另一角度印证：**EBITDA 比 EBIT 更能反映宝钢在弱周期下的现金创造能力。**

**口径披露：**
- 简单平均，各年权重 1/4 相等（非加权）；对 2022-2025，简单与近权平均差异 <5%，不改变定性。
- 2022/2023 固定资产折旧为邻年插补，已披露。
- 灵敏度档位：中位数 EPS 0.510/ROE 5.49%；线性近权 EPS 0.457/ROE 4.93%。

**待办**：乐观情景正常化尚未计算，故仅呈现悲观情景。

## 5. 关键假设与局限

**关键假设（必须披露）：**
1. 下一周期（2022 起）盈利中枢弱于上一周期（2015-2021），δ 由 2022-2025 实测校准（EBIT -29%、EBITDA -10%）。
2. 悲观主口径 = 2022-2025 简单平均（各年权重 1/4）。
3. EBIT 近似口径（营业利润 + 财务费用），略低估、方向保守；EBITDA = EBIT + 折旧摊销。
4. **2022/2023 固定资产折旧为邻年插补**（源数据缺失），宝钢该科目历年稳定在 ~190 亿，插补误差小。
5. 净债务未扣受限货币资金，约影响每股 0.1-0.3 元。
6. 估值倍数：EV/EBITDA 5-7x、周期中性 PE 8-12x，取值为判断项。
7. **主锚为 EV/EBITDA**（重资产业较适用），PE 作交叉验证——这是 v2 修正的核心口径选择。

**方法局限（方法论 §6）：**
- 若地产需求中枢下移是**永久性结构变化**，历史窗口简单平均可能系统性高估——以"下一周期更弱"假设缓释，但若下移持续（2024 仅 3.7% ROE），未来中枢可能更低。
- 窗口选择、统计量、估值倍数均有判断空间。
- 期货主连非现货，价差仅方向参考。
- EBITDA 未扣资本开支，高 EBITDA ≠ 高自由现金流（`ev-ebitda.md` §5），需结合 capex 强度验证。

## 6. 结论（中间产物）

- **悲观情景合理价区间（主锚 EV/EBITDA）**：约 **6.8 ~ 10.0 元**
- **悲观情景合理价区间（副锚 PE）**：约 **3.8 ~ 5.7 元**
- **当前价**：5.86 元（当前隐含 EV/EBITDA 4.4x、PE 12.3x）
- **悲观情景当前估值判断**：☐ 偏高　**☑ 合理/偏便宜**（EV/EBITDA 主锚）　☐ 合理（PE 副锚）
- **核心逻辑（修正后）**：补上折旧摊销改用 Normalized EBITDA(342.8亿) 配钢铁 5-7x 后，合理价下沿 6.80 元已高于当前价 5.86 元；当前隐含 EV/EBITDA 4.4x 低于行业正常化区间。若承认地产不可逆下移、按下周期悲观中枢估值，宝钢**不再偏贵，处于合理偏便宜区间**。
- **待办**：① 乐观情景估值；② PE 与 EV/EBITDA 分歧的交叉验证（如 EV/吨产能、PB-ROE）；③ 敏感性分析（窗口扰动、受限资金±、倍数扰动）；④ 视需核对 2022/2023 折旧精确值于年报附注。
