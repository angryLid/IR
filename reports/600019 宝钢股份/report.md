## 1. 周期识别

### 1.1 数据来源与口径

财务数据取自 `analysis_codes/data/financial/` 下新浪财经三大报表 CSV（单位：万元），覆盖 **2014-2025 年报**，另含 2015-2025 现金流量表（折旧摊销）。计算脚本：
- `analysis_codes/identify_cycle.py` → 逐年盈利序列 → `data/derived/annual_earnings_series.json`
- `analysis_codes/exogenous_cycle_evidence.py` → 外生周期证据
- `analysis_codes/normalized_pessimistic_A.py` → 悲观正常化（EBIT 口径）
- `analysis_codes/ebitda_series.py` → 逐年 EBITDA 序列（含折旧摊销）→ `data/derived/ebitda_series.json`

**关键口径**（方法论 §3.1）：
- EBIT（近似）= 营业利润 + 财务费用（免费源不拆分利息明细，方向保守，略低估）
- EBITDA = EBIT + 折旧摊销（固定资产折旧 + 无形资产摊销 + 长期待摊费用摊销；新浪免费页未见使用权资产折旧单列，按 0 并披露）
- ROE = 归母净利润 ÷ 归母净资产
- 期货数据为**主力连续免费替代**（新浪主连），仅用于方向/分位辅助，不代表当期钢厂毛利

**数据缺口与处理（2026-08-24 披露）**：新浪现金流量表在 2022（年报列）与 2023（全年）缺失"固定资产折旧"行，已重抓验证为源数据缺陷。因宝钢该科目历年稳定在 ~190 亿（2017-2025 同量级），**经用户确认，对 2022/2023 用相邻有值年份线性插补**，并在 `ebitda_series.json` 中 `da_interpolated=True` 标记。插补值 184.5/185.0 亿与真实值一致（2021:183.9、2024:185.6）。

**外生证据（避免循环论证）：**

4. **统计工具**：盈利与价格/需求拐点（2015 谷、2021 顶）相互印证。✓

## 2. 正常化盈利计算

### 2.1 框架

$$\text{Normalized(下一周期)} = \text{Normalized(基准周期 2015-2021)} \times (1 - \delta)$$

δ 由 2022-2025 已发生数据校准。当 δ = 1 − (下周期均值/基准均值) 时上式恒等于 2022-2025 直接均值（数学恒等）。

### 2.2 基准周期正常化（2015-2021，简单平均）

| 指标 | 基准均值(2015-2021) |
|------|--------------------|
| Normalized EPS | 0.663 元 |
| Normalized ROE | 8.34% |
| Normalized EBIT | 213.7 亿 |
| Normalized EBITDA | 380.8 亿 |

### 2.3 悲观情景正常化（方法 A：2022-2025 均值）

| 指标 | 悲观 Normalized（2022-2025 均值） | 相对基准下移 δ |
|------|----------------------------------|----------------|
| **Normalized EPS** | **0.478 元** | -28% |
| **Normalized ROE** | **5.23%** | -37% |
| **Normalized EBIT** | **151.0 亿** | -29% |
| **Normalized EBITDA** | **342.8 亿** | **-10%** |
| Normalized EBIT利润率 | 4.45% | -41% |
| Normalized EBITDA利润率 | 10.15% | — |

**重要**：EBITDA 的下移幅度（-10%）远小于 EBIT（-29%），因为折旧摊销（反映存量产能，不随当前盈利大幅波动）在周期下行期充当了"盈利缓冲垫"，使 EBITDA 相对稳定。这也从另一角度印证：**EBITDA 比 EBIT 更能反映宝钢在弱周期下的现金创造能力。**

**口径披露：**
- 简单平均，各年权重 1/4 相等（非加权）；对 2022-2025，简单与近权平均差异 <5%，不改变定性。
- 2022/2023 固定资产折旧为邻年插补，已披露。
- 灵敏度档位：中位数 EPS 0.510/ROE 5.49%；线性近权 EPS 0.457/ROE 4.93%。

**待办**：乐观情景正常化尚未计算，故仅呈现悲观情景。

## 5. 关键假设与局限

**关键假设（必须披露）：**
1. 下一周期（2022 起）盈利中枢弱于上一周期（2015-2021），δ 由 2022-2025 实测校准（EBIT -29%、EBITDA -10%）。
2. 悲观主口径 = 2022-2025 简单平均（各年权重 1/4）。
3. EBIT 近似口径（营业利润 + 财务费用），略低估、方向保守；EBITDA = EBIT + 折旧摊销。
4. **2022/2023 固定资产折旧为邻年插补**（源数据缺失），宝钢该科目历年稳定在 ~190 亿，插补误差小。
5. 净债务未扣受限货币资金，约影响每股 0.1-0.3 元。
6. 估值倍数：EV/EBITDA 5-7x、周期中性 PE 8-12x，取值为判断项。
7. **主锚为 EV/EBITDA**（重资产业较适用），PE 作交叉验证——这是 v2 修正的核心口径选择。

**方法局限（方法论 §6）：**
- 若地产需求中枢下移是**永久性结构变化**，历史窗口简单平均可能系统性高估——以"下一周期更弱"假设缓释，但若下移持续（2024 仅 3.7% ROE），未来中枢可能更低。
- 窗口选择、统计量、估值倍数均有判断空间。
- 期货主连非现货，价差仅方向参考。
- EBITDA 未扣资本开支，高 EBITDA ≠ 高自由现金流（`ev-ebitda.md` §5），需结合 capex 强度验证。

## 5.5 PB 周期回归（PB-Cycle Regression）—— 交叉验证条目，方法判定为失效

> **定位**：完成 §6 待办 ②"PE 与 EV/EBITDA 分歧的交叉验证"。执行 `methodology/pb-cycle-regression.md`，与周期平均法（Normalized Earnings × EV/EBITDA）做交叉验证。
> 执行日期：2026-08-24　适用方法论：`methodology/pb-cycle-regression.md`
> 脚本：`analysis_codes/pb_cycle_regression.py`　数据：`analysis_codes/data/derived/pb_series.json`、`pb_regression.json`

### 5.5.1 数据与口径

- **股价**：AKShare 取 600019 日线（**不复权**），取每年最后交易日收盘价。源：腾讯 `stock_zh_a_hist_tx`（东方财富 `stock_zh_a_hist` 当日持续断连，回退腾讯；**两源年度收盘价经交叉核对完全一致**）。抓取日期 2026-08-24。
- **BPS** = 归母净资产 ÷ 217.82 亿股（现行总股本统一口径，历史股本可能小幅变动，已披露）。
- **PB** = 年末收盘价 / BPS；**景气指标 = ROE**（归母净利/归母净资产，用户选定）。
- 样本窗口：**2015-2025（11 年）**，与现有周期框架一致。

|---|---|---|---|---|
| 2015 | 5.58 | 5.179 | 1.08 | 0.90 |
| 2016 | 6.35 | 5.567 | 1.14 | 7.39 |
| 2017 | 8.64 | 7.549 | 1.14 | 11.66 |
| 2018 | 6.50 | 8.115 | 0.80 | 12.20 |
| 2019 | 5.74 | 8.174 | 0.70 | 6.98 |
| 2020 | 5.95 | 8.464 | 0.70 | 6.88 |

PB 区间 **0.63 ~ 1.14，平均约 0.85**；ROE 区间 0.90% ~ 12.38%，峰谷约 14 倍——**盈利本身高度周期**。

### 5.5.3 回归结果

**基准全样本（2015-2025）：`PB = 0.808 + 0.0040 × ROE`，R² = 0.006**

- **斜率 β₁ = 0.004**：ROE 每升 1pct，合理 PB 仅抬 0.004；ROE 从 0.9%→12.4%，拟合 PB 仅 0.81→0.85。
- **R² = 0.006**：ROE 仅解释 PB 波动的 **0.6%**，回归近乎退化成一条水平线。

**窗口敏感性**：

| 窗口 | 回归线 | R² | ROE=5.23%→合理PB →合理价 |
|---|---|---|---|
| 全样本 2015-2025 | PB=0.808+0.004×ROE | 0.006 | 0.829 → 7.84 元 |
| 2017-2025 | PB=0.563+0.027×ROE | 0.336 | 0.704 → 6.67 元 |
| 2022-2025 下周期 | PB=0.999−0.056×ROE | **0.656** | 0.704 → 6.67 元 |

**纵向对比（当前价隐含）**：当前价 5.86 元、BPS 9.465 → **隐含 PB = 0.619**。

### 5.5.4 方法失效分析（核心）

**为何 PB-ROE 回归在宝钢不成立：**

1. **斜率 ≈ 0，解释力趋零**（R²=0.006）。PB 周期回归的核心假设是"景气度高 → 合理 PB 高"。宝钢 11 年里，ROE 峰值年（2017/2021，ROE≈12%）PB 仅 0.80-1.14，而低景气年（2019-2020，ROE≈7%）PB 也是 0.70——**拟合线几乎是水平线**。β₁≈0 说明"用景气度解释 PB"这个函数在宝钢手上退化成常数，方法的增量价值（把固定倍数升级为景气度函数）没有实现。
2. **斜率不稳定、甚至符号颠倒**。2017-2025 斜率 +0.027；仅取 2022-2025 下周期斜率 **−0.056**（R² 反而最高 0.656）——即最近四年"ROE 越低、PB 反而越高"（2024-25 盈利最差但 PB 从 0.63 抬回 0.79）。关系形状随窗口剧烈改变，无法外推，回归线本身不可靠。
3. **根因是"股价被去周期化定价"，而非"企业不周期"**。宝钢**盈利高度周期**（ROE 峰谷 14 倍、EPS 峰谷 18 倍），但**市场长期把宝钢的 PB 摁在净资产附近（0.63~1.14）**，净资产一路增厚到 2062 亿而股价未同步跟上。市场已将其定价为"净资产收益常年偏低、成长性低"的稳定标的，**PB 不再随景气度走**——这是行业结构变化（地产需求中枢下移、钢铁龙头长期 ROE 中枢下移）下的**估值范式切换**，属于方法论 §5 警示的"行业结构变化使历史回归关系外推失效"与"对弱周期不敏感""不适用于重定价标的"的叠加情形。

**结论（交叉验证角色）**：本方法在宝钢**统计上失效**，不宜作为估值主锚。其唯一有信息量的输出是——**当前隐含 PB 0.619 处于自身历史区间（0.63~1.14）的偏低端**，与 EBITDA 主锚的"当前价偏便宜/合理"方向一致，但这一结论来自"如今 PB 绝对值低"这一事实本身，而非回归线。故本条目仅作**现状观察与方向佐证**，估值权重交给 §6 的 EBITDA/PE 主锚。
