## 二、银行专用指标计算

### 2.1 ROA（总资产收益率）

- ROA 2025 = 3,389.06 / [(45,631.82 + 40,571.15) / 2] = 3,389.06 / 43,101.48 = **0.79%**
- ROA 2024 = 3,355.77 / [(40,571.15 + 40,294.39) / 2] = 3,355.77 / 40,432.77 = **0.83%**
- ROA 2023 = 3,326.53 / [(40,294.39 + 38,000.00) / 2] ≈ **0.85%**（估算）
- 趋势：**下降**（0.85% → 0.83% → 0.79%）

### 2.2 NIM（净息差，估算）

- 利息净收入(2025估算) = 营业收入 - 投资收益 - 手续费佣金收入(估约1200亿) ≈ 7,610.49 - 491.44 - 1,200 ≈ 5,919亿
- 平均生息资产(2025) ≈ 43,101亿
- NIM 2025(估) ≈ 5,919 / 43,101 ≈ **1.37%**
- NIM 2024(估) ≈ 6,055 / 40,433 ≈ **1.50%**
- 趋势：**下降约13bps**

### 2.3 非息收入占比（估算）

- 非息收入(2025) = 投资收益 + 手续费佣金 ≈ 491 + 1,200 ≈ 1,691亿
- 非息收入占比 = 1,691 / 7,610 = **22.2%**
- 趋势：小幅提升（投资收益从214亿增至491亿）

### 2.4 成本收入比（估算）

- 营业税金及附加(2025) = 91.38亿
- 业务及管理费 = 营业收入 - 营业利润 - 利息支出中非成本项... 受限于数据精度，估算约 30-32%
- 趋势：基本稳定

### 2.5 股息相关

- 派息率历史：约30%
- DPS 2025(估) = 1.30 × 30% ≈ **0.39元**
- DPS 2024 ≈ 0.393元
- DPS 2023 ≈ 0.389元
- DPS 2022 ≈ 0.389元
- DPS 2021 ≈ 0.364元
- DPS CAGR (2021-2025) = (0.39/0.364)^(1/4) - 1 = **1.76%**
- 当前股息率 = 0.39 / 10.03 = **3.89%**

> 注：NPL、拨备覆盖率、资本充足率等指标未能从当前数据源获取。

## 三、DDM 估值

### 3.1 参数设定

| 参数 | 取值 | 依据 |
|------|------|------|
| DPS_0 | 0.39元 | 2025 EPS 1.30 × 30% 派息率 |
| g1（阶段一增长率） | 2.5% | 近5年DPS CAGR 1.76%，适度上调 |
| N（阶段一年限） | 5年 | 银行股标准假设 |
| g_terminal（终端增长率） | 2.5% | 略低于中国长期名义GDP增速 |
| r（COE，基准） | 9.5% | CAPM：Rf 2.0% + Beta 0.7 × ERP 7.5% = 7.25%，考虑银行特有风险上调至9.5% |

### 3.2 基准情形计算 (COE=9.5%, g1=2.5%, g_terminal=2.5%)

| 年份 | DPS | 折现因子 | PV |
|------|-----|---------|-----|
| 1 | 0.3998 | 1.095 | 0.365 |
| 2 | 0.4098 | 1.199 | 0.342 |
| 3 | 0.4200 | 1.313 | 0.320 |
| 4 | 0.4305 | 1.438 | 0.299 |
| 5 | 0.4413 | 1.574 | 0.280 |
| **PV合计** | | | **1.606** |

- 终端值 TV = 0.4413 × 1.025 / (0.095 - 0.025) = 0.4523 / 0.07 = **6.461**
- PV(TV) = 6.461 / 1.574 = **4.106**
- **DDM内在价值 = 1.606 + 4.106 = 5.71元**
