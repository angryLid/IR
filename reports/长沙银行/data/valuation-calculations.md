## 3. 股息估算

### BPS 变动法反推 DPS

**FY2024:**
- BPS 变动 = 16.67 - 14.95 = +1.72
- EPS = 1.87
- OCI ≈ +9.13亿 / ~42亿股 ≈ +0.22/股
- 假设其他权益变动≈0: DPS = EPS - (BPS变动 - OCI/股) = 1.87 - (1.72 - 0.22) = 0.37
- 派息率 ≈ 19.8%

**FY2025:**
- BPS 变动 = 17.66 - 16.67 = +0.99
- EPS = 1.93
- OCI ≈ -12.59亿 / ~42亿股 ≈ -0.30/股
- DPS = 1.93 - (0.99 - (-0.30)) = 1.93 - 1.29 = 0.64
- 派息率 ≈ 33.2%

**两年均值:**
- DPS ≈ (0.37 + 0.64) / 2 = 0.505
- 派息率 ≈ 26.5%
- 当前股息率(按0.505) = 0.505 / 8.95 = 5.6%
- 当前股息率(按0.64) = 0.64 / 8.95 = 7.2%

- DDM 基准 (DPS=0.55): 9.50
- PB+ROE 基准: 10.60
- RIM 基准: 18.34 (假设净资产公允)

**加权综合估值:**
