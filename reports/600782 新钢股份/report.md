### 4.5 两种方法分歧的方法论风险警示（重点）

前述路线一（EV/EBITDA 主锚 3.35~4.51 元）与路线二（PE 副锚 1.02~1.53 元）差距极大（约 3 倍以上）。**这个差距并非计算错误，而是同一估值被同一套"净利润/EBITDA 转化漏斗"放大后的必然结果，它本身是盈利质量极差的信号旗。** 推理如下：

**1）两种方法在理论上本应自洽（换算恒等式）**

隐含 PE 与 EV/EBITDA 通过归母净利润、净债务联结：

$$\text{隐含PE} = \frac{\text{EV/EBITDA 倍数} \times \text{EBITDA} + \text{净现金}}{\text{归母净利润}}$$

代入新钢悲观数（EBITDA 18.6 亿、归母净利 4.1 亿、净现金 13.7 亿）：

| 表面倍数 | 反推隐含 PE | | 表面倍数 | 反推隐含 EV/EBITDA |
|---------|------------|-|---------|-------------------|
| EV/EBITDA 5x | **26.2x** | | PE 8x | 1.01x |
| EV/EBITDA 6x | **30.8x** | | PE 10x | 1.45x |
| EV/EBITDA 7x | **35.4x** | | PE 12x | 1.88x |

即：主锚 5-7x 表面"便宜"，实则等价于隐含 PE 26~35x；PE 8-12x 表面"合理"，实则等价于隐含 EV/EBITDA 仅 1.0~1.9x。**两条路线并非两个独立估值，而是同一答案用不同倍数刻度。**

**2）分歧根源：新钢净利润/EBITDA 转化率仅 22%（折旧占 64%）**

```
EBITDA 18.6亿 ── [D&A 11.8亿 = 64%] ──> EBIT 6.8亿 ──> 归母净利润 4.1亿
```

- 归母净利润只有 EBITDA 的 **21.9%**（宝钢约 30%，损耗 70%）；
- 新钢损耗 78%，其中大头是 **11.8 亿折旧摊销**——它本质是维持性资本开支的会计计提，**不是可分配现金流**（`ev-ebitda.md` §5：高 EBITDA ≠ 高自由现金流）。

**3）方法失真的方向不同，PE 更诚实**

| | EV/EBITDA 主锚 | PE 副锚 |
|--|----------------|---------|
| 是否扣 D&A、税 | 否 | 是 |
| 对新钢 | **系统性高估**：把维持产能必需的折旧误当可分配现金 | 扣掉真实资本替代成本 → 更接近股东实际回报 |
| 隐含反推 | 5-7x 表面便宜，实为 26-35x PE | 10x 表面贵，实为 1.0-1.9x EV/EBITDA |

对一个净利润趋零(ROE 1.54%、净利率 ~0.1%)的公司，**PE 路线的信息更诚实**——它回答"股东每年真正赚到的钱（4.1 亿）市场给多少倍"；而 EV/EBITDA 把大额折旧当现金，正是方法论警示的陷阱在新钢身上被放到最大。

**4）对综合判断的含义**

- 巨大的方法分歧本身 = **"这家公司盈利质量在行业极低端"的警示**，不应简单"取中间值"或"加权平均"掩盖掉。
- EV/EBITDA 主锚的"便宜"结论依赖"折旧可兑现"假设，对净利率趋零的新钢**不稳健**，需以质量折价档（4x）和 PE 路线交叉压降。
- 质量折价档（4x → 合理价 2.76 元 ≈ 现价 2.74 元）实质上是**对 EV/EBITDA 主锚失真的隐性校正**——把隐含 PE 从 26~35x 压到 21.7x。
- 结论强健性排序（悲观情景）：**PE 信息 > 质量折价档 > EV/EBITDA 主锚**（对盈利质量趋零公司）。

## 5. PB 周期回归交叉验证（方法与宝钢一致，独立检验）

**样本**：2015-2025 逐年 PB/ROE（BPS 用现行股本 31.84 亿股统一口径）。

| 窗口 | 回归线 | R² | ROE=1.54%→合理PB→合理价 |
|------|--------|-----|------------------------|
| 全样本 2015-2025 | PB=0.817+0.006×ROE | **0.013** | 0.827 → 6.79 元 |
| 剔除前两年 2017-2025 | PB=0.413+0.024×ROE | 0.533 | 0.450 → 3.69 元 |
| 仅下周期 2022-2025 | PB=0.428+0.013×ROE | 0.312 | 0.448 → 3.68 元 |

**方法诊断（与宝钢对照）：**
- **全样本 R²=0.013、斜率近零** → 与宝钢相同，PB-ROE 回归**在全样本统计失效**（2015-2016 高 PB 主要因当期股本远小于现行口径造成的 BPS 低估，口径失真）。
- **但剔除早期异常（2017-2025）后**：斜率 +0.024、R²=0.533，**方向合理**（ROE 高→PB 高），与宝钢"下周期斜率甚至转负"不同——说明去掉股本口径失真后，新钢的 PB-ROE 关系存在。
- **当前隐含 PB = 2.74 / 8.208 = 0.334**，处历史区间（剔除口径失真后 0.41-1.57）**最低端**；仅下周期窗口给出的合理 PB（0.448→3.68 元）高于当前价隐含的 0.334。

**结论（交叉验证角色）**：PB 回归全样本虽失效，但滑动窗口与"当前 PB 处历史最低分位"的现状观察，与 EV/EBITDA 主锚"当前价偏便宜/合理"方向一致——当前市价处历史 PB 低端，且低至质量折价档附近。

## 7. 关键假设与局限

**关键假设：**
1. 下一周期（2022 起）盈利中枢弱于上一周期，新钢下移幅度（ROE −90%）由 2022-2025 实测校准。
2. 悲观主口径 = 2022-2025 简单平均（各年等权）。
3. EBIT 近似口径（营业利润 + 财务费用），略低估、方向保守；EBITDA = EBIT + 折旧摊销。
4. 净债务按受限货币资金 = 0 处理（新钢为净现金，此处理对估值影响方向与宝钢相反，需注意）。
5. 估值倍数：EV/EBITDA 5-7x（主锚、另 4x 质量折价档）、周期中性 PE 8-12x，取值均为判断项。
6. **主锚为 EV/EBITDA**，PE 作交叉验证——与宝钢一致。

**方法局限：**
- 若地产下行是永久性结构变化，历史窗口简单平均可能系统性高估——新钢 2024-2025 已接近 0 盈利，未来中枢甚至可能为 0 或亏损。
- 新钢近利润中枢极低，EV/EBITDA 的相对稳定性（折旧缓冲）在此已很弱（EBITDA 利润率也仅 3.2%），估值对周期位置非常敏感。
- 净现金口径：受限资金未扣，若受限比例高会高估净现金、高估股权价值。
- PB 全样本回归因股本口径变化失真（早期 BPS 被高估股本摊薄），滑动窗口才有效。

## 8. 看多 vs 看空

**看多论点：**
1. 现价 2.74 元处历史 PB 最低分位（隐含 PB 0.334），EV/EBITDA 主锚显示低于行业 5-7x 下沿。
2. 资产负债表为**净现金 −13.7 亿**，无债务压力，困境中有财务缓冲。
3. 宝武体系成员（2022 年并入），可能获集团采购/协同赋能。
4. 若地产/基建需求边际企稳，低估值基数下弹性大（板带材周期性）。

**看空论点：**
1. 盈利中枢近乎归零（Normalized ROE 1.54%），基本面处于亏损边缘。
2. 产品结构（中厚板/建材、毛利率 2-7% 甚至线材为负）高度暴露于地产下行，盈利能力弱于行业。
3. 若结构下行持续，正常化盈利可能进一步下修，当前"便宜"可能是价值陷阱。
4. 净利率极低导致 PE 失真，若用 PE 考量则明显偏贵（21.5x）。

## 9. 结论（悲观情景 · 中间产物）

- **悲观合理价区间（路线一 EV/EBITDA 5-7x）**：约 **3.35 ~ 4.51 元**
- **悲观合理价区间（副锚 PE 8-12x）**：约 **1.02 ~ 1.53 元**
- **质量折价档（4x）**：约 **2.76 元** ≈ 当前价 2.74 元
- **当前价**：2.74 元（隐含 EV/EBITDA 3.96x、PE 21.5x、PB 0.334）
- **当前估值判断（悲观）**：EV/EBITDA 主锚 → 偏便宜或合理；PE 副锚 → 贵；质量折价档 → 市场已定价到位
- **核心逻辑**：用 Normalized EBITDA（18.6 亿）配钢铁 5-7x 主锚时，合理价下沿 3.35 元高于当前价 2.74 元；但市场实际给出的 EV/EBITDA 3.96x 已隐含了低于行业中枢的质量折价，恰好落在单列的质量折价档（4x → 2.76 元）。**两家公司的估值差异（新钢折价 vs 宝钢质量溢价）全部可归因于公司盈利质量差异，无污染。**
- **待办**：乐观情景估值；敏感性分析（倍数扰动、净现金受限±、周期窗口）；宝钢已完成的 PB 回归失效处理在此替换为"滑动窗口有效"的判断结论。
