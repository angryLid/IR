## 8. 方法一致性换算（EV/EBITDA vs PE 分歧根源，报告 §4.5）

**归一化盈利链条（亿元）：**
```
Normalized EBITDA = 18.56 亿
  其中 折旧摊销 D&A = 11.80 亿（占 EBITDA 64%）
  其中 EBIT       = 6.76 亿
归母净利润 = Normalized EPS 0.128 × 股本 31.84 = 4.06 亿
净利润/EBITDA 转化率 = 4.06 / 18.56 = 21.9%
```

**换算恒等式：** 隐含PE = (EV/EBITDA 倍数 × EBITDA + 净现金) ÷ 归母净利润

| 表面倍数 | 反推隐含 PE | | 表面倍数 | 反推隐含 EV/EBITDA |
|---------|------------|-|---------|-------------------|
| EV/EBITDA 5x | 106.5/4.06 = **26.2x** | | PE 8x | (32.5−13.7)/18.56 = 1.01x |
| EV/EBITDA 6x | 125.1/4.06 = **30.8x** | | PE 10x | (40.6−13.7)/18.56 = 1.45x |
| EV/EBITDA 7x | 143.6/4.06 = **35.4x** | | PE 12x | (48.7−13.7)/18.56 = 1.88x |
| 质量折价 4x | 88.0/4.06 = **21.7x** | | — | — |

> 注：EV/EBITDA 法股权加回净现金（−13.7 → +13.7）；PE 法反推 EV = 市值 + 净债务。
