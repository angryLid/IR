# EV/EBITDA（企业价值倍数）方法论

> 适用对象：重资产、高负债、折旧摊销占比高的行业（钢铁、煤炭、电力、化工等），以及需要跨公司横向比较的场景
> 撰写日期：2026-08-23

## 一、方法的基本逻辑

**EV/EBITDA = 企业价值（Enterprise Value）/ 息税折旧摊销前利润（Earnings Before Interest, Taxes, Depreciation and Amortization）**

- **分子 EV** 代表"买下整家公司（含偿还债务）要花多少钱"，而不仅仅是买股票的钱。将债务纳入分子，是为了让估值口径同时覆盖股东与债权人。
- **分母 EBITDA** 代表公司主营业务的"现金创造能力"，剔除了利息（资本结构）、所得税（税负差异）、折旧摊销（会计政策）这三项与主营经营无关或人为可调的因素。

倍数含义：EV/EBITDA = 8x，即按当前盈利水平，全资收购这家公司（含偿还债务）约需 8 年 EBITDA 才能覆盖收购总成本。

## 二、与 PE 的对应关系

| 指标 | 分子（付多少钱） | 分母（赚多少钱） | 口径 |
|------|----------------|----------------|------|
| PE | 市值（只买股票） | 净利润（归股东） | 只看股东 |
| EV/EBITDA | EV = 市值 + 负债 − 现金（买下整家公司） | EBITDA（税前息前折旧前） | 股东 + 债权人 |

EV/EBITDA 在同一估值逻辑上修正了 PE 的两个失真点：

1. **分子修正**：PE 只算市值、忽略债务。两家市值相同的公司，一家负债 300 亿、一家负债 50 亿，买下它们的真实成本差很多。
2. **分母修正**：净利润中混着利息、税、折旧这些与主营经营无关或人为可调的因素。EBITDA 剥掉这些，更接近"这家公司本身每年能产出多少现金"。

## 三、适用场景

- **重资产行业**：折旧摊销占成本比例高，净利润被压薄且波动大，PE 失真或为负时无法使用。
- **高负债行业**：只看市值会低估"买下公司"的真实成本。
- **跨公司横向比较**：EBITDA 剔除了资本结构、税负、折旧政策差异，比净利润更适合横向对比。

## 四、计算方法

### 4.1 原始数据

> 以下所有财务数据取自合并报表口径（年报），市场数据取最新交易日。强周期行业需同时收集 10-12 年历史序列（见"历史序列"部分）。

**（1）市场数据**

| 数据项 | 字段/来源 | 含义 |
|--------|-----------|------|
| 总市值 | 最新收盘价 × 总股本 | 按当前股价买下全部股权需支付的对价 |
| 总股本 | 含限售股在内的全部股本 | 计算市值与每股价值的分母 |

**（2）资产负债表数据（有息负债与现金，取自最新年报）**

| 数据项 | 字段/来源 | 含义 |
|--------|-----------|------|
| 短期借款 | 资产负债表"短期借款" | 一年内需偿还的有息借款 |
| 一年内到期的非流动负债 | 资产负债表对应科目 | 其中含一年内到期的长期借款、应付债券 |
| 长期借款 | 资产负债表"长期借款" | 偿还期超过一年的有息借款 |
| 应付债券 | 资产负债表"应付债券" | 公司发行的债券融资 |
| 租赁负债 | 资产负债表"租赁负债"（新租赁准则后） | 融资租赁及经营租赁资本化形成的负债 |
| 货币资金 | 资产负债表"货币资金" | 账面现金及银行存款 |
| 受限资金 | 年报附注"货币资金"明细（质押、冻结、保证金等） | 不可自由动用的资金，计算净现金时必须扣减 |

> **口径要点**：EV 分子只含**有息负债**，不含应付账款、预收款项等经营性占款；现金必须扣减受限部分，否则 EV 被高估。

**（3）利润表数据（逐年，强周期行业取 2015-2025）**

| 数据项 | 字段/来源 | 含义 |
|--------|-----------|------|
| 净利润 | 利润表"净利润"（合并口径） | 含少数股东损益的全部净利润 |
| 所得税费用 | 利润表"所得税费用" | 当期利润总额对应的所得税 |

**（4）现金流量表补充资料（逐年）**

| 数据项 | 字段/来源 | 含义 |
|--------|-----------|------|
| 利息费用 | 财务费用附注"利息费用"（非净额） | 当期实际计提的借款利息；不能用"财务费用"合计数（混入汇兑损益、利息收入） |
| 固定资产折旧 | 补充资料"固定资产折旧" | 当期计提的固定资产折旧 |
| 使用权资产折旧 | 补充资料"使用权资产折旧" | 租赁资产当期折旧 |
| 无形资产摊销 | 补充资料"无形资产摊销" | 当期无形资产摊销 |
| 长期待摊费用摊销 | 补充资料"长期待摊费用摊销" | 当期长期待摊费用摊销 |

**（5）历史序列与周期证据（强周期行业必需）**

| 数据项 | 含义 |
|--------|------|
| 过去 10-12 年（2015-2025）的利润表与现金流量表数据 | 逐年计算 EBITDA 序列，用于周期识别与正常化 |
| 钢价指数（螺纹钢、热轧卷板） | 同步/领先的景气证据，识别周期顶点与谷底 |
| 铁矿石价格、焦炭价格 | 原材料成本端，解释盈利波动来源 |
| 地产新开工面积、基建投资增速 | 下游需求证据，判断波动是周期性还是结构性 |
| 政策事件（供给侧改革、产能置换等） | 外生冲击，佐证周期边界 |

### 4.2 计算方法

**Step 1：逐年计算 EBITDA**

```
EBITDA_t = 净利润_t + 所得税费用_t + 利息费用_t + 折旧摊销_t
其中 折旧摊销_t = 固定资产折旧_t + 使用权资产折旧_t + 无形资产摊销_t + 长期待摊费用摊销_t
```

**Step 2：计算 EV（当前口径，用于与市场对比）**

```
EV_当前 = 总市值 + 有息负债 − 现金及等价物
有息负债 = 短期借款 + 一年内到期的非流动负债 + 长期借款 + 应付债券 + 租赁负债
现金及等价物 = 货币资金 − 受限资金
```

**Step 3：周期正常化（强周期行业必做，详见周期平均法方法论）**

```
识别完整周期窗口（谷底 → 峰值 → 谷底，需外生证据）
Normalized EBITDA = mean(EBITDA_t)，t ∈ 周期窗口
（备选：剔除峰值/谷底年后取均值，或给近年轻度加权）
```

**Step 4：估值倍数**

```
行业正常化 EV/EBITDA 倍数：钢铁行业一般取 5-7x
（倍数区间做敏感性分析：低/中/高三档）
```

**Step 5：反推价值**

```
合理 EV = Normalized EBITDA × EV/EBITDA 倍数
股权价值 = 合理 EV − 有息负债 + 现金及等价物
每股价值 = 股权价值 ÷ 总股本
```

**Step 6：对比判断**

```
当前 EV/EBITDA = EV_当前 ÷ 当年 EBITDA（仅作参考，单年被周期扭曲）
将合理每股价值区间与当前股价对比，判断偏高/合理/偏低
```

### 4.3 计算结果

**最终产出结果集：**

| 结果项 | 说明 |
|--------|------|
| 逐年 EBITDA 序列（2015-2025） | 周期识别的输入，也是正常化计算的基础 |
| 周期窗口判定 | 明确包含谷底与顶点的年份区间，附外生证据 |
| Normalized EBITDA | 周期中性盈利水平，估值的分母基准 |
| 合理 EV 区间 | Normalized EBITDA × 倍数区间（含敏感性三档） |
| 合理股权价值区间 | EV − 净债务（有息负债 − 现金及等价物） |
| 合理每股价值区间 | 股权价值 ÷ 总股本 |
| 当前 EV/EBITDA | 用当前市值反算的倍数，与行业正常化倍数对比 |

**结果数据集内部关系（链式依赖）：**

```
逐年 EBITDA 序列 ──周期识别──> 周期窗口
周期窗口 ──取统计量──> Normalized EBITDA
Normalized EBITDA × 倍数区间 ──> 合理 EV 区间
合理 EV 区间 − 净债务 ──> 合理股权价值区间
合理股权价值区间 ÷ 总股本 ──> 合理每股价值区间
合理每股价值区间 vs 当前股价 ──> 估值高低结论
```

即：**每一级结果都是上一级的确定性函数**。EBITDA 序列和周期窗口决定 Normalized EBITDA；Normalized EBITDA 与倍数共同决定 EV；EV 与净债务决定股权价值；股权价值与股本决定每股价值。因此敏感性分析只需对两个自由度做：**周期窗口/正常化口径** 与 **EV/EBITDA 倍数**，其余结果随之联动，无需独立估计。

## 五、方法的局限

- **忽略资本开支**：EBITDA 未扣除维持经营所需的资本开支，高 EBITDA 不等于高自由现金流，需结合 FCF 或 capex 强度验证。
- **对轻资产行业不直观**：低负债、净利润稳定的公司，PE 更直观。
- **分子口径陷阱**：EV 中的"总负债"应含有息负债（含租赁负债），不含经营性占款；现金应扣减受限现金。口径不一致时倍数不可比。
- **EBITDA 可被操纵**：非经常性损益、一次性项目可被计入，需核查计算口径。
- 因此实践中常与 PB-ROE、EV/吨钢产能、EV/FCF 等指标交叉验证。
