# 周期平均法（Cyclical Earnings Normalization）方法论

> 适用对象：强周期、重资产、盈利随产品价格剧烈波动的行业（钢铁、煤炭、有色、化工等）
> 撰写日期：2026-08-23

## 一、方法的基本逻辑

强周期公司的单年盈利被周期位置严重扭曲，不能拿某一年（尤其最近一年）的盈利直接估值。周期平均法的核心思想是：**平滑掉周期波动，算出"一个完整景气周期下的正常盈利水平"（Normalized Earnings），再乘以正常化估值倍数。**

它回答的问题是：这家公司在"平均景气"下能赚多少钱？当前市场价又隐含了什么预期？

### 方法与盈利路径的关系

- 周期底部取当年盈利 → 系统性低估，可能给出"破产价"
- 周期顶部取当年盈利 → 系统性高估，可能给出"成长股溢价"
- 周期平均 → 锚定在"平均景气下的盈利能力"，避免两头失真

## 二、适用场景

- **强周期行业**：盈利随产品价格剧烈波动，单年盈利被周期位置严重扭曲（钢铁、煤炭、有色、化工）。
- **重资产行业**：盈利波动大、周期特征明显，ROE 从峰值到谷底差距 2-3 倍以上。
- **判别标准**：过去 10-12 年盈利序列中必须能明确看到至少一次波峰与波谷，且峰谷差距足够大——否则方法失去意义。

## 三、计算方法

### 3.1 原始数据

> 以下财务数据取自合并报表口径（年报），市场与价格数据按各自频率收集。强周期行业需覆盖 10-12 年（1.5-2 个周期）历史序列。

**（1）盈利数据（逐年，2015-2025）**

| 数据项 | 字段/来源 | 含义 |
|--------|-----------|------|
| 营业收入 | 利润表"营业收入" | 计算利润率的分母 |
| 净利润 | 利润表"净利润"（归母口径） | 周期识别最直接的盈利序列 |
| EPS | 利润表/公告"基本每股收益" | 正常化盈利的候选指标 |
| EBIT | 利润表：营业利润 + 利息费用（附注口径） | 息税前利润，剔除资本结构后的盈利能力，用于 EV/EBITDA 组合 |
| EBIT 利润率 | EBIT ÷ 营业收入 | 跨公司比较更稳定 |
| 净资产 | 资产负债表"归母净资产" | 计算 ROE 的分母 |
| ROE | 归母净利润 ÷ 归母净资产（或年报披露） | 周期识别核心指标，同时供 PB 回归交叉验证 |

**（2）行业价格数据（外生证据，月度或日度）**

| 数据项 | 来源 | 含义 |
|--------|------|------|
| 螺纹钢价格指数 | 中钢协/我的钢铁网 | 长材价格，同步或领先盈利 |
| 热轧卷板价格指数 | 同上 | 板材价格，同步或领先盈利 |
| 铁矿石价格（普氏指数） | 普氏/公开数据 | 原材料成本端，驱动盈利波动 |
| 焦炭价格 | 公开数据 | 原材料成本端 |
| 钢材-原材料价差 | 钢价 − 原料成本折算 | 盈利的直接驱动指标 |

**（3）宏观与需求数据（外生证据，年度/月度）**

| 数据项 | 来源 | 含义 |
|--------|------|------|
| 地产新开工面积 | 国家统计局 | 建筑钢材核心需求，判断周期还是趋势 |
| 基建投资增速 | 国家统计局 | 板材/长材需求 |
| 制造业 PMI | 国家统计局 | 制造业景气度，板材需求 |
| 政策事件（供给侧改革、产能置换、环保限产） | 公开政策文件 | 外生冲击，佐证周期边界 |

**（4）估值倍数与市场数据（用于最终估值）**

| 数据项 | 来源 | 含义 |
|--------|------|------|
| 行业正常化 EV/EBITDA 倍数 | 钢铁行业惯例 5-7x，可比公司验证 | 正常化 EBIT 的估值倍数 |
| 周期中性 PE | 行业历史中枢或可比公司 | 正常化 EPS 的估值倍数（备选） |
| 总市值 | 最新收盘价 × 总股本 | 与合理价值对比 |
| 总股本 | 全部股本 | 换算每股价值 |
| 有息负债 | 短期借款 + 长期借款 + 应付债券 + 租赁负债 + 一年内到期非流动负债 | 计算净债务 |
| 货币资金（扣受限） | 资产负债表附注 | 计算净债务 |

### 3.2 计算方法

**Step 1：识别一个完整周期（定义正常化盈利的样本窗口）**

```
窗口必须同时包含景气顶点与谷底，取"谷底到谷底"（或峰值到峰值），而非"谷底到峰值"。
判定"完整"的标准是波形完整，不是时间够长。

四层证据（由硬到软）：
1. 盈利本身：过去 10-12 年 ROE/EPS/EBIT 利润率，必须出现至少一次明显的峰与谷，峰谷差距 2-3 倍以上
2. 行业价格：钢价指数、原材料价差，同步/领先盈利
3. 宏观与需求：地产新开工、基建投资、PMI、政策事件
4. 统计工具：HP 滤波/滚动平均分离趋势与周期成分，拐点即周期边界

关键原则：周期识别必须用外生证据（价格、需求、政策），不能用盈利序列本身定义窗口再取平均——那是循环论证。

输出：周期窗口 [T1, T2]（如钢铁 2015-2025，含谷底 2015/2016 与顶点 2021）
```

**Step 2：计算正常化盈利（Normalized Earnings）**

```
对窗口内各年的 EPS、EBIT、ROE 分别取统计量：

简单平均：Normalized = mean(X_t)，t ∈ [T1, T2]        （盈利围绕中枢对称波动时）
加权平均：Normalized = Σ(w_t × X_t)，近期权重更高      （兼顾周期与成长/结构变化时）
中位数：  Normalized = median(X_t)，t ∈ [T1, T2]       （窗口内有暴利/巨亏异常年份时）

对应产出：
Normalized EPS、Normalized EBIT、Normalized ROE
```

**Step 3：正常化盈利 × 正常化估值倍数**

```
主估值（EV/EBITDA 组合）：
  合理 EV = Normalized EBIT × 行业正常化 EV/EBITDA（钢铁 5-7x）
  股权价值 = 合理 EV − 净债务（有息负债 − 货币资金）
  每股价值 = 股权价值 ÷ 总股本

备选（PE 组合）：
  合理股价 = Normalized EPS × 周期中性 PE

交叉验证：
  Normalized ROE 代入 PB 周期回归（见 pb-cycle-regression.md），互验合理价
  或使用 EV/吨钢产能等产能类指标
```

### 3.3 计算结果

**最终产出结果集：**

| 结果项 | 说明 |
|--------|------|
| 周期窗口判定 | 起止年份 + 外生证据链（价格/需求/政策），解释"为什么这个窗口是代表性的" |
| 逐年盈利序列 | 10-12 年 EPS / EBIT / ROE，周期识别的输入与展示 |
| Normalized Earnings | 正常化 EPS / EBIT / ROE，含敏感性变体（去峰谷年、加权、中位数） |
| 合理估值倍数 | 行业 EV/EBITDA 区间、周期中性 PE，含来源依据 |
| 合理价值区间 | 合理 EV → 股权价值 → 每股价值（含敏感性三档：乐观/基准/悲观） |
| 估值结论 | 合理每股价值区间 vs 当前股价，判断偏高/合理/偏低 |

**结果数据集内部关系（链式依赖）：**

```
逐年盈利序列 ──周期识别（外生证据）──> 周期窗口 [T1, T2]
周期窗口 ──取统计量（均值/加权/中位数）──> Normalized Earnings（EPS/EBIT/ROE）
Normalized EBIT × 行业 EV/EBITDA ──> 合理 EV
合理 EV − 净债务 ──> 合理股权价值
合理股权价值 ÷ 总股本 ──> 合理每股价值
合理每股价值 vs 当前股价 ──> 估值高低结论
```

即：**每一级结果都是上一级的确定性函数**。正常化盈利由窗口和统计量决定；合理价值由正常化盈利与倍数决定。因此敏感性分析只需对三个自由度做：**周期窗口**、**统计量选择（正常化口径）**、**估值倍数**，其余结果随之联动，无需独立估计。

## 四、识别周期与正常化盈利的关系

**识别周期定义了"平均的样本空间"，计算正常化盈利是对这个空间取统计量——前者是后者有效性的前提。**

1. **正常化盈利本质上是"周期平均"，而平均必须先有边界。** 周期的起止点就是答案；没有周期识别，"取最近 N 年"只是随手一划，结果完全取决于落笔位置。
2. **识别周期保证样本的代表性，而代表性是平均无偏的前提。** 对钢企，取 2019-2023（只有下行）与取 2015-2025（谷底到下行），正常化盈利可能差 50% 以上——差别不在算法，在窗口。
3. **识别必须用外生证据，否则循环论证。** 不能拿平均值定义平均值。
4. **两步共享同一个底层信念：均值回归。** 若识别阶段确认结构性拐点（如地产需求中枢下移），就不该用长窗口简单平均。

一句话：**识别周期回答"均值回归的参照系在哪"，计算正常化盈利回答"回归到的水平是多少"。参照系错了，度量再精确也没有意义——在潮汐周期里测的可能是涨潮水位，却拿它当海平面。**

## 五、落地建议（以钢企为例）

1. 取 2015-2025（11 年）或 2017-2025（9 年，后供给侧时代）作为主窗口——明确包含谷底（2015-2016）与顶点（2021）。
2. 计算去掉峰值年（2021）和谷底年（2015/2016）后的"周期中性盈利"，做敏感性展示。
3. 若地产需求中枢下移被判定为结构性变化，对极端谷底年份的处理要谨慎：可给近年轻度加权，或以 2017-2025 为主窗口。
4. 把周期识别依据（价格、需求、政策）写进报告——能解释"为什么这个窗口是代表性的"，比追求数学上完美的周期定义更有说服力。

## 六、方法的局限

- **窗口选择主观**：平均几年、是否加权、权重如何设定，均有判断空间。
- **假设历史周期重复**：若行业进入结构性下行（如地产需求中枢下移），历史平均会系统性高估。
- **对弱周期行业不敏感**：盈利波动不足以区分周期与噪音时，方法失去意义。
- 因此实践中常与 PB-ROE 周期回归、EV/吨钢产能等指标交叉验证。
