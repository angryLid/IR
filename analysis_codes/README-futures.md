# 期货行情数据管道（免费源 akshare）

钢材（长材/板材）与铁矿石价差研究的**可编程数据层**。当前只使用**免费期货行情**（akshare → 交易所/东方财富接口）。
现货价（Mysteel、普氏 IODEX 等）为付费源，作为**校验基准**存在，未纳入免费管道。

> 本文档是 README.md（新浪财报管道）之外**独立的第二条管道**说明。重点不是操作步骤，而是——
> **用免费期货数据做价差研究的口径局限**，让任何后续研究都清楚"这份代码算出的价差代表什么、不代表什么"。

## 数据规模与范围

| 品种 | 交易所 | 合约符号 | 用途 |
|------|--------|----------|------|
| 螺纹钢（长材代表） | 上期所 SHFE | RB 主力 | 长材价 |
| 热轧卷板（板材代表） | 上期所 SHFE | HC 主力 | 板材价 |
| 铁矿石 | 大商所 DCE | i 主力 | 原料价 |

akshare 提供日线/分钟线，可自由聚合为月线（月成交价 = 当月成交额 / 成交量，或月末收盘，视口径而定）。

## ⚠️ 免费期货数据的局限（必读）

以下局限决定了：**期货价差 ≠ 钢厂当期真实毛利**，只能用于**方向与周期位置的判断**，不能用于精确刻画钢厂当下盈利。

### 1. 期货与现货的价差性质不同（最重要的局限）

- **现货价差**（螺纹/热卷现货价 − 铁矿现货价）反映钢厂**当下真实**采购成本与销售价格，是**当期毛利**的驱动。
- **期货价差**是两个**远月合约**之间的市场定价，内含市场对未来两端的**预期**，不是"现在发生了的真实毛利"。
- 更关键的是**方向可能相反**：市场预期未来钢材需求转弱时，成材期货（RB/HC）**先跌**，铁矿（原料）因供应反应慢**后跌、跌得慢**，期货价差先被打压甚至转负——这在现货端可能尚未发生。即著名的**"期货先行、现货滞后"**。用它判"钢厂当下赚不赚钱"会明显误判。

### 2. 主力合约换月的"跳空"

- "主力合约"随持仓/成交转移而切换（如 RB 从 2601 → 2605），切换瞬间两个合约价差会**跳空**，若不处理会污染月度序列。
- 用"主连"（akshare 的连续合约）通常已做衔接处理，但**不同接口的衔接规则不同**，需标注采用的是哪条主连。

### 3. 合约月份不一致

- 螺纹、热卷、铁矿各有不同的上市/交割月份，**它们的主连不一定是同一次交割月**。
- 因此"期货价差"的三个腿可能不是同一到期月份，跨品种相减在**定价视角上严格不一**。

### 4. 基差（贴水/升水）≠ 0

- 期货价偏离现货价（基差）常态存在且在换月前后剧烈波动。用期货绝对价做周期分位基本可靠，但**用期货价减去现货价去反推值得怀疑**。

### 5. 不含钢厂其他成本

- 即便用现货，吨钢毛利还= 钢材价 −（铁矿 + **焦炭** + 废钢 + 电 + 折旧 + 人工…）。
- 免费期货管道**只覆盖铁矿石一条原料腿**，焦炭（大商所 J 主连）尚未纳入，完整毛利需补充，否则价差只是"钢材−铁矿"的近似代理变量。

## 免费 vs 付费源的价值分工

| 研究目的 | 唯一可靠口径 | 免费期货管道能否满足 |
|----------|--------------|----------------------|
| 钢价/矿价各自**历史周期位置**（分位/高低） | 期货即可 | ✅ 满足 |
| 钢材−矿石价差**方向与拐点** | 现货（Mysteel + 普氏） | ⚠️ 仅能跟踪方向，需现货校验 |
| 钢厂**当期精确吨钢毛利** | 现货 + 焦炭/废钢等 | ❌ 不能满足 |

**结论**：免费期货管道定位为**"量价跟踪 + 周期分位 + 方向预判"**的自动化前端；
一旦研究进入"当期盈利"环节，必须接入现货/普氏付费源做校验基准。当前阶段受预算约束，先只建免费管道。
